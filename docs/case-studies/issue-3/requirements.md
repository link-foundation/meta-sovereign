# Requirements for Issue #3

| ID    | Requirement                                                                          | State                                                                                                                                                      |
| ----- | ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| R-N1  | Support access to email providers through existing mail protocols and provider APIs. | Done: `email` source supports JMAP, Gmail API, Microsoft Graph, and Node local-server IMAP/POP3/SMTP modes.                                                |
| R-N2  | Try provider requests directly in the browser where possible.                        | Done: JMAP/Gmail/Graph use `fetch()` and the server CSP permits HTTPS provider calls.                                                                      |
| R-N3  | Fall back to requests via local server.                                              | Done: `POST /api/email/pull` and `POST /api/email/send` proxy email operations through the local server.                                                   |
| R-N4  | Allow receiving mail.                                                                | Done: archive import plus live `pullMessages()` for HTTP APIs plus IMAP/POP3 through `createNodeEmailTransport()`.                                         |
| R-N5  | Allow sending mail.                                                                  | Done: live `post()` for Gmail, Microsoft Graph, JMAP, and SMTP through `createNodeEmailTransport()`.                                                       |
| R-N6  | Import data from email providers.                                                    | Done: `.eml`, mbox, Gmail API message payloads, Microsoft Graph messages, JMAP Email records, and generic JSON records normalize into `msg:email:*` links. |
| R-N7  | Export in the unified format.                                                        | Done: email messages are normal store links and therefore flow through existing `export` and encrypted export paths.                                       |
| R-N8  | Add user-facing connection guidance.                                                 | Done: connection guides include Email, archive hints, API credential hints, and browser-vs-local-server protocol notes.                                    |
| R-N9  | Compile issue data and case-study analysis under `docs/case-studies/issue-3/`.       | Done: issue JSON, comments JSON, requirements, solution plan, component survey, external research, and implementation notes are present.                   |
| R-N10 | Verify the implementation with tests.                                                | Done: source registry/archive tests, live adapter tests, raw protocol transport tests, and local server fallback route tests cover the new email surface.  |
