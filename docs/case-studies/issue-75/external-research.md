# External research

| Source                                                                                                                                                                                                                                                                                                                                              | Observation and application                                                                                                                                                                                                                                                          |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [Telegram public names and invite links](https://core.telegram.org/api/invites), [channel constructor](https://core.telegram.org/constructor/channel) and [full channel constructor](https://core.telegram.org/constructor/channelFull)                                                                                                             | Public usernames and invite-only access are distinct. Read the current channel and require a main public username or an active additional username. Use the channel's default send-as identity for authorship when present.                                                          |
| [Telegram history](https://core.telegram.org/method/messages.getHistory), [forum topics](https://core.telegram.org/api/forum) and [forum topic constructor](https://core.telegram.org/constructor/forumTopic)                                                                                                                                       | A non-forum chat's newest history item and a selected topic's `top_message` are different boundaries. Fetch exactly the relevant tail. An inaccessible, deleted or closed topic cannot provide an eligible tail.                                                                     |
| [Telegram messages and sender fields](https://core.telegram.org/constructor/message), [edit RPC](https://core.telegram.org/method/messages.editMessage), [styled entities](https://core.telegram.org/api/entities) and [cloud drafts](https://core.telegram.org/api/drafts)                                                                         | Telegram edits by peer and message ID, reports refusals for authorship and age, and returns updates. The edit schema has no compare-and-swap or clear-draft parameter. Preserve original entities and offset new ones in UTF-16 code units.                                          |
| [Pinned Telegram Web A edit method](https://github.com/Ajaxy/telegram-tt/blob/f67a40879a7d78c2683ec5a296cf55bc22417d56/src/api/gramjs/methods/messages.ts#L1049) and [pinned T3 Code settings](https://github.com/pingdotgg/t3code/blob/08a463e29976617134de01e9341f898bc881d0eb/apps/web/src/components/settings/AppearanceSettingsPanel.tsx#L461) | Telegram passes the message ID, plain text and entities through a provider edit. T3 Code puts user preferences in labeled settings rows with adjacent help. Meta-Sovereign uses its existing local controls and update path. [Repository reference index](../../CHAT-REFERENCES.md). |
| [Stream React MessageList grouping](https://getstream.io/chat/docs/sdk/react/v14/components/core-components/message-list/#message-grouping)                                                                                                                                                                                                         | Groups adjacent messages for display. The provider still holds separate messages, so this would only improve the local view.                                                                                                                                                         |
| [Matrix event replacements](https://spec.matrix.org/latest/client-server-api/#event-replacements) and [Slack chat.update](https://docs.slack.dev/reference/methods/chat.update/)                                                                                                                                                                    | Both have genuine edit semantics and ownership checks. They point to the correct provider capability shape, but this repository has neither adapter.                                                                                                                                 |
| [VK's messaging schemas](https://github.com/VKCOM/vk-api-schema/tree/master/messages) and [the VK integration](../../../js/src/sources/vk.js)                                                                                                                                                                                                       | VK includes history, editing and join invitations. The conversation fields available to the app do not establish the public membership boundary needed for this setting. A community inbox represents communication with the community and differs from a public conversation.       |

The installed Teleproto client already implements Telegram history, topic reads and edits. The repository's formatting, message-limit and update handling cover the other primitives. Adding a chat UI SDK or a second Telegram client would duplicate these pieces without changing the provider's edit semantics.
