Ключ доступа сообщества
Ключ доступа (токен) сообщества позволяет вызывать методы VK API от имени сообщества или публичной страницы. Такой ключ доступа нужен в сценариях, где действие должно выполняться от имени сообщества — например, для переписки с подписчиками. При создании ключа доступа сообщества ему предоставляются определённые 
права
.
Способ получения ключа доступа зависит от типа приложения и от того, где выполняется код: в серверной или клиентской части приложения.

Особенности работы
•
Получить ключ доступа может только администратор этого сообщества.
•
Срок действия ключа доступа сообщества не ограничен. Если ключ скомпрометирован, вы можете его 
отозвать
.
•
Все созданные ключи доступа отображаются в настройках сообщества.
Права доступа
Права доступа определяют, с какими разделами данных может работать ключ доступа. Например, для получения фотографий сообщества нужен ключ доступа с правами 
photos
. Подробнее — в разделе 
Права доступа и приватность
.
Получить ключ
Настройки сообщества
Самый простой способ получить ключ доступа — создать его в настройках вашего сообщества. В настройках можно создать несколько ключей с разным набором прав, а также в любой момент отозвать ключ. Чтобы создать ключ:
1.
Откройте сообщество, в котором вы являетесь администратором.
2.
В меню справа выберите 
Управление
 → 
Дополнительно
 → 
Работа с API
.
3.
На вкладке 
Ключи доступа
 нажмите 
Создать ключ
.
Перейти к управлению сообществом
Создать ключ
4.
Выберите права доступа для ключа и нажмите 
Создать
.
5.
Подтвердите действие в мобильном приложении ВКонтакте или по СМС.
После подтверждения ключ появится на вкладке 
Ключи доступа
.
OAuth ВКонтакте
Этот способ подходит, если вы хотите получать ключ доступа сообщества программно.
1.
Получите список сообществ, в которых пользователь является администратором. Для этого необходимо выполнить запрос 
groups.get
 с параметром 
filter=admin
.
2.
Запросите ключ доступа сообщества при помощи одного из сценариев:
•
Если вызовы VK API выполняются на сервере приложения, используйте Authorization Code Flow. Ключ доступа, полученный этим способом, не привязан к IP‑адресу.
Подробнее — в документации VK ID: 
Authorization Code Flow для получения Access token сообщества
.
•
Если вызовы VK API выполняются в клиентском коде на устройстве администратора сообщества, используйте Implicit Flow.
Подробнее — в документации VK ID: 
Implicit Flow для получения Access token сообщества
.
Событие VK Bridge
Если вы разрабатываете мини‑приложение и вызываете VK API из клиентского кода, ключ доступа сообщества можно запросить через событие 
VKWebAppGetCommunityToken
 библиотеки VK Bridge. Этот вариант обычно используют в 
приложениях сообществ
.
Подробнее — в описании события 
VKWebAppGetCommunityToken
.
