## droidnews.ru, 2026-09-13 (updated 2026-09-20), Андрей Матвеев

https://droidnews.ru/kate-mobile-ne-rabotaet-posle-blokirovki-vk-chem-zamenit-klient-i-pochemu-v-lente-chuzhie-posty

- «10 сентября техподдержка VK ответила разработчикам Kate Mobile напрямую»: the free limit was used up, and further quota is paid.
- About a million users, «примерно 3 млрд запросов к API в месяц», VK ID price «полкопейки за запрос», «около 15 млн рублей ежемесячно».
- The quota resets on 1 October, which would last «в лучшем случае на день-два».
- Alternatives listed: Fenrir for VK (login error about too many password attempts), the official client, the web version, and a Fellin mod (some accounts frozen on first login; fake copies circulating).
