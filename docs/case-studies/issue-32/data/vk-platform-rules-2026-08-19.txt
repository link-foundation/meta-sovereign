Обновление политики использования VK API
ВКонтакте обновляет политику работы с VK API для сторонних сервисов и приложений. Все интеграции должны использовать только методы, опубликованные в 
официальной документации
, и соблюдать установленные лимиты. Методы, не входящие в публичную документацию, будут поэтапно ограничены.
С 
7 сентября 2026 года
 для одного аккаунта в 
Кабинете для бизнеса VK ID
 устанавливаются лимиты на количество вызовов методов VK API в месяц:
•
Для партнёров без верификации бизнес-профиля — 10 000 вызовов в месяц.
•
После верификации бизнес-профиля — 100 000 000 вызовов в месяц.
Для получения лимита свыше 100 000 000 необходимо связаться с VK по адресу 
devsupport@corp.vk.com
.

Офертой об использовании VK ID

Используя публичный API ВКонтакте, вы соглашаетесь с перечисленными Правилами платформы.
Эти правила распространяются на любые способы использования публичного API. Кроме того, в отдельных случаях применяются дополнительные соглашения и требования:

Правила размещения приложений-магазинов

Правила для ботов

Термины и определения
1. Социальная сеть ВКонтакте (или Социальная сеть)
 — социальная сеть, известная под именем «ВКонтакте», размещённая на сайте в сети интернет по адресу vk.ru (включая все уровни указанного домена, как функционирующие на дату принятия пользователем настоящих Правил, так и запускаемые и вводимые в эксплуатацию в течение всего срока его действия) и доступная Пользователю через сайт, мобильную версию сайта, приложения и иные ресурсы, представляющая результат интеллектуальной деятельности в форме программы для ЭВМ, являющейся, помимо прочего, уникальной базой данных ООО «ВК». Социальная сеть представлена в объективной форме совокупностью данных и команд и порождаемых аудиовизуальных отображений (включая входящие в её состав графические изображения и пользовательский интерфейс, далее — данные и команды), предназначенных для функционирования ЭВМ и мобильных устройств в целях получения определённого результата в виде организации функциональности социальной сети. Совокупность данных и команд состоит из активированных и неактивированных данных и команд.
2. Публичный API
 — совокупность программных средств для работы с данными Социальной сети посредством HTTP-запросов. Под методами публичного API понимаются методы, перечисленные на странице 
https://dev.vk.ru/method
, а также методы, указанные в Условиях использования Публичного API, размещённых по ссылке 
https://id.vk.ru/about/business/go/legal/vkid/tariffs
. Доступ к Публичному API может быть прекращён полностью или частично без уведомления и объяснения причин. Использование Публичного API должно соответствовать условиям технической документации, доступной по адресу 
https://dev.vk.ru
, а также иным условиям, указанным в настоящих Правилах платформы.
3. Приложение
 — программный продукт для работы с Публичным API, представляющий собой сайт или автономную программу, зарегистрированный посредством формы 
https://dev.vk.ru/ru/admin/create-app
 и имеющий в Социальной сети уникальный идентификатор (API_ID).
4. ООО «ВК»
 — общество с ограниченной ответственностью «ВК», юридическое лицо, созданное по законодательству Российской Федерации и зарегистрированное по адресу: 125167, г. Москва, Ленинградский проспект, д. 39, стр. 79.
1. Функциональность Приложения
1.1.
 Приложение не должно обманывать пользователей.
Не стоит обещать бесплатные голоса или просмотр гостей страницы.
1.2.
 Приложение не должно содержать функций, при работе с которыми пользователь нарушает Правила пользования Социальной сетью ВКонтакте (
https://vk.ru/terms
).
Например, приложение для помощи в накрутке лайков — плохая идея.
1.3.
 В Приложении не должно быть ссылок, опасных для пользователей. Все переходы по ссылкам должны быть предсказуемы.
Если в вашем приложении много разных ссылок от пользователей, используйте метод 
utils.checkLink
, чтобы проверить их безопасность.
1.4.
 Приложение не может быть выдано за официальный продукт разработчиков ООО «ВК». В том числе запрещается использовать логотип, подарки или стикеры Социальной сети ВКонтакте в оформлении, использовать название Социальной сети ВКонтакте в названии или описании Приложения и / или указывать на иную аффилированность с ООО «ВК», если иное не оговорено отдельным дополнительным соглашением.
1.5.
 Нельзя резко изменять суть и название Приложения.
Если такая необходимость возникла, зарегистрируйте новое. Пользователи будут неприятно удивлены, обнаружив у себя в списке какое-то незнакомое приложение.
1.6.
 Нельзя предоставлять возможность скачивать контент (например, аудиозаписи, видеозаписи, изображения, документы и другое) с серверов ООО «ВК» за рамками предоставляемой Социальной сетью ВКонтакте функциональности с целью предоставления доступа к контенту в офлайн-режиме или создания автономных хранилищ с использованием такого контента.
Это нарушает интересы ООО «ВК», пользователей и/или правообладателей.
1.7.
 Приложение не должно содержать сторонних библиотек, фрагментов кода, не имеющих прямого отношения к его функционированию, в том числе эксплуатирующих вычислительные мощности устройства пользователя без его ведома.
Тайком майнить криптовалюту — нельзя.
1.8.
 В случае технической необходимости мы оставляем за собой право перенести ваше Приложение на другую нашу платформу, сохраняя все технические характеристики Приложения.
2. Работа с данными
Мы трепетно относимся к данным наших пользователей и ожидаем от вас того же. Приложениям запрещено:
2.1.
 Собирать и хранить пользовательские данные, включая идентификатор пользователя (User ID), в целях, не связанных с функционированием Приложения. Запрашиваемые данные должны использоваться только в контексте приложения.
Например, кешировать идентификаторы друзей пользователя, чтобы быстрее отображать список на мобильном устройстве, — можно. Передавать идентификаторы всех пользователей к себе на сервер, чтобы хранить в собственной базе на всякий случай, — нельзя.
2.2.
 Передавать любые пользовательские данные, автоматизированно полученные через API (включая User ID), сторонним сервисам (например, рекламным) как напрямую, так и через посредников.
2.3.
 Использовать пользовательские данные в любых рекламных объявлениях.
Например, обращаться к пользователю по имени из рекламного баннера. Не надо так.
2.4.
 Данные, полученные через API, в том числе методами 
newsfeed.search
, 
wall.get
, 
wall.search
 в том числе идентификаторы пользователей (User ID), не могут использоваться в целях передачи или перепродажи, создания аналитических отчётов, скоринга и т. д. напрямую или через посредников без прямого согласия ООО «ВК».
Таким согласием, например, может быть договор с рекламным агентством на использование данных о показах рекламных объявлений в отчётах клиентам.
