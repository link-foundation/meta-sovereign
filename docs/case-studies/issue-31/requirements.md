## Assumptions

- "Personal contacts" means 1:1 conversations in the imported archives
  (Telegram, VK, e-mail, …), not address-book entries without a dialog —
  without a dialog there is nothing to measure the silence or the form
  of address from.
- The silence is measured from the last message in either direction.
- When the evidence is absent or tied, "вы" is the safer default.
- "Debug mode" in the issue is the same thing as "safe mode"; both
  names are accepted (`debug` is normalized to `safe`).
- "Regular chat is enough" is read as: nothing new to open — drafts and
  the automation menu live in the chat screen that already existed.
- "Use link-cli to do it fast" is read as: link-cli holds the reply
  graph, but the keystroke path must not wait on it, because every
  link-cli query today scans the whole store (see the README's Q&A).
