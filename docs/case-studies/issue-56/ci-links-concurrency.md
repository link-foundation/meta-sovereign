# Link checker concurrency and transient server errors

[PR 57](https://github.com/link-foundation/meta-sovereign/pull/57) keeps unresolved links as CI failures while reducing the load of checking the reference inventory.

On `32253199`, [run 42859450035](https://github.com/link-foundation/meta-sovereign/actions/runs/42859450035) failed three attempts on changing GitHub source URLs. Attempt 1 reports three translated references to one Signal file returning HTTP 503 (log lines 427–437). Attempt 2 passes that source but reports two Matrix references returning 503 (431–435). Attempt 3 reports 42 errors across different GitHub sources (summary line 459). The first two URLs returned 200 when checked directly. Their complete logs are retained in the [PDF evidence archive](data/forms-reviewed-upload.tar.gz). These observations do not establish a single remote root cause, and rerunning unchanged input did not resolve the failures.

The workflow previously used lychee's default request concurrency. [Lychee's guidance](https://lychee.cli.rs/troubleshooting/rate-limits/) recommends reducing concurrent requests to ease remote load. The workflow now permits four requests, retains three retries with two-second initial backoff and excludes 408, 429 and 5xx results from the cache. Those settings follow the documented [retry behavior](https://lychee.cli.rs/troubleshooting/network-errors/) and [cache flags](https://lychee.cli.rs/guides/cli/). Successful responses may still be cached. No status is newly accepted and no URL is excluded. The existing final failure step, finite job deadline and archived report remain enforced.

Seventeen focused existing CI contract checks pass, and the workflow policy validator confirms the bounded job, pinned runner and read-only checkout settings. The [local command logs and workflow snapshot](data/ci-links-concurrency.tar.gz) have a [verified manifest](data/ci-links-concurrency.tar.sha256.json). The exact-head hosted link check must verify this mitigation against the actual references. Other CI failures and all issue-wide acceptance criteria remain required.
