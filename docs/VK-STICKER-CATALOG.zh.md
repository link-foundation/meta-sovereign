# VK 贴纸目录

在连接 → VK 中打开贴纸目录，输入已连接账户的 ID。查看保存的目录不会
连接 VK。手动刷新读取已购买的启用包、关键词和问候包。只有已购买、
已启用且明确允许使用的贴纸才标为可用。保存的权限只是快照，后续发送
仍可能被拒绝。错误、不完整响应和账户变更都会保留之前确认的快照。

按关键词或 ID 搜索，选择包或类别，并以每页 100 条浏览。一个包中的
所有可用问候 ID 都会保留。在贴纸页面选择 VK 收藏，切换贴纸选择后
点击保存，重新加载后仍保留手动选择。

收到的附件筛选接受 JSON 对象或数组，仅保留正数贴纸/产品 ID，列出
去重产品。收到贴纸并不证明拥有它或有权发送。此筛选可离线使用。

导出会保存贴纸包、可用贴纸、关键词、问候 ID、当前筛选和可选的收到
ID，JSON 分卷最多 1500 行。请指定服务器电脑上应用存储之外的新绝对
路径，父文件夹必须已存在。已有路径会被拒绝。保留预览链接，不下载
图像。所有分卷成功后才写入清单。失败后检查部分文件，并换一个新
文件夹重试。刷新不会发送消息或购买贴纸。

命令、参数及 Lino API 见[完整指南](VK-STICKER-CATALOG.md)。保存目录
查看和附件筛选可离线使用；刷新及文件导出需要连接服务器。
