# Давние беседы ВКонтакте ([en](VK-DORMANT-CONVERSATIONS.md) · [hi](VK-DORMANT-CONVERSATIONS.hi.md) · [zh](VK-DORMANT-CONVERSATIONS.zh.md))

В «Подключения → VK» доступны отдельные вопросы о теме, предложения помощи и
вопросы о музыке. Расписания выключены. Каждый режим сохраняет свой интервал,
лимит отправки и просмотра друзей, срок тишины, паузу для человека, приветствие
или стикер, варианты вопроса и защищённые ID. Только онлайн включено. Для темы
по умолчанию требуется семь дней тишины, для помощи и музыки — 31. Лимит ноль
не допускает отправки.

Задайте свои вопросы: по варианту на строку, до 20 вариантов по 500 символов.
Просмотр выбирает и фиксирует вариант для каждого человека. Для музыки укажите
нативный `audioOWNER_ID_AUDIO_ID`; чужие записи из примера не выбираются.
Аудио прикрепляет VK без локальной загрузки или скачивания файла.

Просмотр проверяет текущую дружбу, аккаунт, разрешение писать и полную историю
до 1000 сообщений с резервом места для последовательности. Пустые, недавние,
непрочитанные, защищённые, отключённые владельцем, деактивированные и неизвестные
беседы исключаются. Список ограничен 10 000 друзей; настройка просмотра ограничивает
проверки бесед. Защита приоритетных ID общая с другими политиками дружбы VK.

Подтвердите порядок: приветствие, необязательное аудио, вопрос. Между шагами
15 секунд, между людьми 30. Каждая отправка имеет отдельную запись исходящих и
положительный ID сообщения VK. После фактической паузы ограничения API повторно
проверяются разрешение, политика, согласие, аккаунт и история. Новый ответ,
правка или изменение вложения останавливают продолжение. Просмотр действует
пять минут. Текст и ID аудио сохраняются в чате.

Определённая частичная отправка требует новой ручной проверки. Исходные
оставшиеся сообщения и random ID переживают перезапуск; подтверждённые шаги не
повторяются. Неизвестная отправка блокируется для ручного расследования исходящих.
Расписание не продолжает частичные последовательности. Новый цикл требует и
тишины, и паузы для человека. Остановка завершает принадлежащую сервису работу.

Команды `vk-topic`, `vk-help`, `vk-music` поддерживают `status|save|plan|run`.
Сохранение принимает `--enabled=true|false`, `--every-minutes`, `--limit`,
`--scan-limit`, `--stale-days`, `--cooldown-days`, `--greeting`, `--sticker-id`,
`--questions`, `--online-only=true|false`, `--priority=ID,ID`, а музыка — `--audio`.
Хранилище задаётся `--store`. После `plan` используйте
`run --plan=<возвращённый-id> --confirm=true`. Команда не запускает расписание.
Те же операции доступны через `/api/vk/topic`, `/api/vk/help`, `/api/vk/music` и
`/plan`, `/run` в двух форматах Lino. Офлайн сохраняются настройки; для чтения
VK и отправки требуется локальный сервер.
