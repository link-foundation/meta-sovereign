## Scope now

The priority now is complete display of every message in private chats, groups and channels. Exotic features stay parked and are listed here to come back to later. Only features reachable through the API (MTProto, layer 232, via the `telegram` package) or through the network's web app in a browser are implemented; what only the official apps can do is marked "Not accessible".

Nothing is in progress now. Parked: R-Y215 to R-Y219.

## Legend

- **Status**: Supported = works; Partial = works with the limit named in the notes (work in progress now is marked so); Parked = started, then stopped on the user's request, unfinished work kept in worktrees; Not supported = not built.
- **Access**: API = MTProto methods (named where known); Web = the network's web app in a browser, as a fallback (R-Y38); API + Web = API first, web app when the API has no such call or refuses; Not accessible = needs a capability only the official apps have.
- **Requirements**: the R-Y rows in [`REQUIREMENTS.md`](./REQUIREMENTS.md) that deliver the feature, each with what is done and its known limits.
- **Verification**: most features are tested with fakes and are not checked against real Telegram unless a note says so. The display census of the real store (counts only) covered media photo, document, webpage, poll, contact, dice, story, geo and 283 unsupported messages, all common entities, and service actions such as ChatJoinedByRequest, InviteToGroupCall, ChatEditPhoto, BoostApply and NewCreatorPending.
