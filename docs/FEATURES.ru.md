# Матрица поддержки функций (languages: [en](FEATURES.md) • [zh](FEATURES.zh.md) • [hi](FEATURES.hi.md) • ru)

## Объём сейчас

Сейчас приоритет — полный показ каждого сообщения в личных чатах, группах и каналах. Экзотические функции в парковке, они перечислены здесь, чтобы вернуться к ним позже. Реализуется только то, что доступно через API (MTProto, слой 225, пакет `telegram`) или через веб-приложение сети в браузере; то, что умеют только официальные приложения, помечено «Недоступно».

Делается сейчас: R-Y220 rich-сообщения и обновление схемы до текущего слоя; R-Y221 текст для каждого вида служебных сообщений, сущности «банковская карта», «форматированная дата» и «diff», медиа прямого эфира и атрибуты превью ссылок. В парковке: R-Y213 — R-Y219.

## Обозначения

- **Статус**: Поддерживается = работает; Частично = работает с ограничением из примечания (то, что делается сейчас, так и помечено); В парковке = начато, затем остановлено по просьбе пользователя, незавершённая работа лежит в worktree; Не поддерживается = не сделано.
- **Доступ**: API = методы MTProto (названы, где известны); Веб = веб-приложение сети в браузере, как запасной путь (R-Y38); API + Веб = сначала API, веб-приложение — когда в API нет такого вызова или он отказывает; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Требования**: строки R-Y в [`REQUIREMENTS.ru.md`](./REQUIREMENTS.ru.md), которые это реализуют, с описанием сделанного и известных ограничений.
- **Проверка**: большинство функций проверено на подделках и не проверено на настоящем Telegram, если в примечании не сказано иное. Перепись показа по реальному хранилищу (только счётчики) охватила медиа photo, document, webpage, poll, contact, dice, story, geo и 283 unsupported-сообщения, все распространённые сущности и служебные действия вроде ChatJoinedByRequest, InviteToGroupCall, ChatEditPhoto, BoostApply и NewCreatorPending.
