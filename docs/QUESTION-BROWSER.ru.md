# Проверенные ответы через браузер

В разделе «Автоматизация → Вопросы и сохранённые ответы» откройте ответы через
браузер провайдера. Те же элементы доступны в меню автоматизации Чата и Оператора.
Выберите провайдера, укажите веб-чат и прочитайте текущий вопрос. Для HH нужен
числовой ID веб-чата или официальный URL; UUID API для этого не подходит.
Необязательный официальный URL отклика выбирает его видимую встроенную переписку.

Проверьте вопрос, источники ответа и точные варианты. Кнопка отправки подтверждает
один конкретный вариант в интерфейсе провайдера. Изменившийся вопрос, недоступные
варианты или ваш черновик блокируют нажатие. Обычные подсказки для начала беседы не
считаются ответами. Для свободного ответа предзаполнение записывает проверенный
черновик только в пустое поле. Отправьте его самостоятельно у провайдера.

Сервер хранит приватную проверку 30 минут. Общая с автоматизацией запись исходящих
защищает вопрос от повторной отправки. Успех требует подтверждённого исходящего
сообщения провайдера. Восстановление статуса читает сохранённые данные, не открывая
браузер и не повторяя нажатие. При потере ответа отправка заблокирована до проверки
статуса. Неизвестный результат сохраняется после перезагрузки и перезапуска:
проверьте чат и разрешите запись в исходящих. Без поддержки сервера или офлайн
успех не имитируется. Проверка возможностей не запускает браузер.

CLI: `automations answers browser show`, `inspect --source=hh --chat=7`,
`select --id=<review-id> --option=Yes --confirm=true`, `status --id=<review-id>`
и `prefill --id=<free-text-review-id>`. Перед ними укажите `meta-sovereign`.
Доверенный сервер предоставляет `GET /api/automations/answers/browser` и
`POST /api/automations/answers/browser/{inspect,prefill,select,status}` в текстовом
и бинарном Links Notation. Для выбора нужны сохранённый ID, точная строка варианта
и логическое `confirm: true`. Проверка использует текущие настройки профиля,
контекста, зарплаты и необязательной модели.

Проверено на изолированных страницах с рабочим отправителем. Настоящий аккаунт,
восстановление вариантов из завершённых анкет бота и автоматические наблюдатели
провайдеров остаются незавершёнными критериями задачи #56.
