# Facebook (Messenger और Instagram) फ़ीचर मैट्रिक्स (languages: [en](facebook.md) • [zh](facebook.zh.md) • hi • [ru](facebook.ru.md))

[Telegram फ़ीचर मैट्रिक्स](../FEATURES.hi.md) पर वापस। यह पृष्ठ केवल Facebook (Messenger और Instagram) के बारे में है।

दायरा एक व्यक्तिगत Facebook खाता (Messenger) है और, अंत में अलग पंक्ति-समूह के रूप में, Instagram Direct। यहाँ कुछ भी असली Facebook या Instagram खाते पर सत्यापित नहीं है: हर परीक्षण नकली (fake) से चलता है, और वेब सेलेक्टर असत्यापित अनुमान हैं (कोड स्वयं यही कहता है)।

व्यक्तिगत खाते के लिए तीन रास्ते हैं। केवल तीसरा व्यक्तिगत इनबॉक्स के लाइव संदेशों के लिए चलता है, और वह असली मार्कअप पर अपरखा है।

1. **आधिकारिक API (Graph API / Messenger Platform)।** एडेप्टर _Page_ access token और Page id के साथ `https://graph.facebook.com/v22.0` का उपयोग करता है। Messenger Platform केवल Pages के लिए है: Page का इनबॉक्स, webhooks, 24-घंटे की मानक संदेश विंडो, और ऐप-भूमिका वालों के सिवा सबके लिए App Review (`pages_messaging`)। **व्यक्तिगत Messenger इनबॉक्स के लिए कोई API नहीं है** (पुरानी `read_mailbox` अनुमति और Chat API जा चुके हैं)। एडेप्टर केवल उसके काम का है जो Page चलाता है। दस्तावेज़: <https://developers.facebook.com/docs/messenger-platform/> , <https://developers.facebook.com/docs/graph-api/reference/page/conversations/> , <https://developers.facebook.com/docs/messenger-platform/send-messages/> .
2. **Download-your-data आर्काइव।** आयातक हर thread का `message_N.json` या `.html` क्रम से पढ़ता और जोड़ता है (R-Z10)। auto-import रेसिपी Accounts Center का "Download your information" पेज खोलती है; Connections पेज `.json` और `.zip` स्वीकार करता है। आर्काइव एक बार का स्नैपशॉट है: एंड-टू-एंड एन्क्रिप्टेड चैट सामान्य एक्सपोर्ट में नहीं होतीं (Meta उन्हें अलग देता है) और नए संदेश नहीं आते। दस्तावेज़: <https://www.facebook.com/help/212802592074644> .
3. **ब्राउज़र में वेब ऐप।** ऐप स्थायी ऑटोमेशन प्रोफ़ाइल में `https://www.facebook.com/messages/` चलाता है: भेजना, हाल के संदेश और चैट सूची पढ़ना, संपादन, unsend, रिएक्ट, फ़ॉरवर्ड। `messenger.com` उपयोग नहीं होता; 2026 में वह पूरा वेब क्लाइंट देता है या नहीं, अनिश्चित है, क्योंकि Meta उसे `facebook.com/messages` में समेट रहा है।

**Instagram Direct।** ऐप में अलग Instagram स्रोत, वेब एंट्री या कनेक्शन गाइड नहीं है; Instagram आर्काइव Facebook रेसिपी से `instagram` लिंक के रूप में आयात होते हैं (R-Z10)। आधिकारिक रास्ते: Instagram Messaging API केवल Page से जुड़े Business और Creator खातों के लिए है, व्यक्तिगत खातों के लिए नहीं (https://developers.facebook.com/docs/instagram-platform/instagram-api-with-instagram-login/messaging-api/ )। व्यक्तिगत इनबॉक्स "Download your information" आर्काइव (Facebook जैसा ही `message_1.json` रूप) और ब्राउज़र में `instagram.com/direct/` से पहुँचा जा सकता है।

**पहुँच से बाहर:** वॉइस और वीडियो कॉल, rooms, वेब ऐप में उपयोगकर्ता के restore PIN के बिना एंड-टू-एंड एन्क्रिप्टेड चैट (PIN प्रवाह में उपयोगकर्ता चाहिए), मोबाइल ऐप की Messenger-विशिष्ट सुविधाएँ (Chat Heads, AR इफ़ेक्ट, भुगतान), और व्यक्तिगत इनबॉक्स की हर API कॉल (कोई है ही नहीं)।

## संकेत

- **स्थिति**: समर्थित = उपयोगकर्ता के चलाए ऐप में शुरू से अंत तक काम करता है; आंशिक = टिप्पणी में बताई सीमा के साथ काम करता है ("सुधार जारी (R-Z<n>)" = सुधार अभी बन रहा है); असमर्थित = पहुँच संभव है पर बना नहीं; पहुँच से बाहर = ऐसी क्षमता चाहिए जो केवल आधिकारिक ऐप में है।
- **पहुँच**: API = नेटवर्क की आधिकारिक API (जहाँ पता हैं, एंडपॉइंट सहित); वेब = ब्राउज़र में नेटवर्क का वेब ऐप, विकल्प के रूप में (R-Y38); आर्काइव = नेटवर्क के डेटा एक्सपोर्ट का आयात; API + वेब = पहले API, और जब API में ऐसी कॉल न हो या मना करे तो वेब ऐप; पहुँच से बाहर = ऐसी क्षमता चाहिए जो केवल आधिकारिक ऐप में है।
- **आवश्यकताएँ**: [`REQUIREMENTS.hi.md`](../REQUIREMENTS.hi.md) के R-ID जो इस फ़ीचर को पूरा करते हैं।
- **सत्यापन**: यहाँ सब कुछ main के कोड और नकली (fake) परीक्षण-प्रतिरूपों के विरुद्ध जाँचा गया है। कुछ भी असली खाते पर सत्यापित नहीं है। टिप्पणियों में "योजना (R-Z<n>)" का अर्थ बाद का काम है, अभी चल नहीं रहा।

## ज्ञात कमियाँ

1. वेब ऐप में व्यक्तिगत इनबॉक्स पढ़ना कमज़ोर और असत्यापित है: भेजने वाला / दिशा नहीं, प्रति खिंचाव 5 चैट, संदेश id नहीं, असली Messenger मार्कअप पर कभी नहीं जाँचा।
2. ठीक किया गया (R-Z10): आर्काइव पार्सर में एक ही मिलीसेकंड के id टकराव, mojibake, खोए अटैचमेंट, रिएक्शन और thread प्रकार। बाकी: एक्सपोर्ट में संख्यात्मक उपयोगकर्ता id नहीं, HTML तिथियाँ केवल अंग्रेज़ी।
3. आर्काइव चैट id thread फ़ोल्डर के नाम हैं, वह संख्यात्मक thread id नहीं जो वेब ऐप को चाहिए, इसलिए आयातित thread से उत्तर देना अब भी विफल होता है; आर्काइव में वह id नहीं है (R-Z10)।
4. Connections पेज पहले Page-टोकन फ़ॉर्म देता है, जबकि व्यक्तिगत उपयोगकर्ता को आर्काइव (हिस्ट्री) और साइन-इन ब्राउज़र (लाइव) चाहिए; शब्दों में यह कहना चाहिए (दस्तावेज़, R-Z13)।
5. Page API कोड के कुछ हिस्से अप्रमाणित या मृत हैं: डिलीवरी-रसीद पार्सर का कोई कॉलर नहीं (R-Z7), webhook का रूट नहीं, प्रोफ़ाइल सिंक अपरखा, भेजने में फ़ाइल जोड़ना या उत्तर देना नहीं।
6. वेब भेजने में स्टिकर, अटैचमेंट, उत्तर, अंतराल नहीं हैं, और उसके सेलेक्टर केवल अंग्रेज़ी और रूसी को कवर करते हैं। अस्पष्ट भेजने की विफलता अब दोबारा नहीं भेजी जाती (सुधार हुआ, R-Z4)।
7. Instagram Direct केवल आर्काइव आयात के रूप में है (R-Z10); लाइव पहुँच नहीं है।
8. कम प्राथमिकता: रिएक्शन, फ़ॉरवर्ड, मित्र सूची, ग्रुप मेटाडेटा और संदेश अनुरोध आर्काइव या वेब से पढ़े जा सकते हैं पर छूट जाते हैं।
