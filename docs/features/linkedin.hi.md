# LinkedIn फ़ीचर मैट्रिक्स (languages: [en](linkedin.md) • [zh](linkedin.zh.md) • hi • [ru](linkedin.ru.md))

[Telegram फ़ीचर मैट्रिक्स](../FEATURES.hi.md) पर वापस। यह पृष्ठ केवल LinkedIn के बारे में है।

## दायरा और पहुँच

1. **आधिकारिक API।** दस्तावेज़: Posts API https://learn.microsoft.com/en-us/linkedin/marketing/community-management/shares/posts-api और Sign In with LinkedIn (OIDC) https://learn.microsoft.com/en-us/linkedin/consumer/integrations/self-serve/sign-in-with-linkedin-v2।
   - सदस्य के लिए स्व-सेवा: `openid profile email` (OIDC `GET /v2/userinfo`: sub, नाम, चित्र, locale, ईमेल) और `w_member_social` (पोस्ट बनाना, टिप्पणी-पाठ को PARTIAL_UPDATE से बदलना और हटाना; चित्र, वीडियो, दस्तावेज़, बहु-चित्र, पोल, लेख, रीशेयर)।
   - **प्रतिबंधित:** `r_member_social` (अपनी पोस्ट, टिप्पणियाँ, लाइक पढ़ना) केवल स्वीकृत उपयोगकर्ताओं के लिए है, इसलिए सामान्य व्यक्तिगत ऐप के लिए `GET /rest/posts?q=author` से अपनी पोस्ट पढ़ना भी उपलब्ध नहीं।
   - **Messaging API केवल पार्टनर के लिए है**, स्व-सेवा पहुँच नहीं (सामान्य जानकारी): व्यक्तिगत संदेश पढ़ना या भेजना नहीं। प्रोफ़ाइल संपादन API भी केवल पार्टनर कार्यक्रमों के लिए है।
2. **ब्राउज़र में वेब ऐप** (linkedin.com/messaging, /in/me): संदेश पढ़ने-भेजने और प्रोफ़ाइल संपादित करने का एकमात्र रास्ता। LinkedIn स्वचालित ट्रैफ़िक को सख़्ती से रोकता है, इसलिए हर ऑटोमेशन में खाता प्रतिबंधित होने का जोखिम है।
3. **डेटा एक्सपोर्ट आर्काइव** (Settings > Get a copy of your data): `messages.csv` आयात होती है। बाकी CSV (Connections, Profile, Positions, Skills, Shares, Comments, Invitations) आयात नहीं होतीं।

पहुँच से बाहर: कॉल, वीडियो मीटिंग, Premium और InMail क्रेडिट, Sales Navigator, रिक्रूटर टूल, नौकरी आवेदन प्रवाह, और वह सब जो केवल ऐप में है।

CV स्क्रीन (`/api/cv/*`) के अलावा LinkedIn के लिए अलग सर्वर रूट या पृष्ठ स्क्रीन नहीं है। संदेश सामान्य कोड से चलते हैं। वेब सेलेक्टर कभी असली साइन-इन LinkedIn पर जाँचे नहीं गए।

## संकेत

- **स्थिति**: समर्थित = उपयोगकर्ता के चलाए ऐप में शुरू से अंत तक काम करता है; आंशिक = टिप्पणी में बताई सीमा के साथ काम करता है ("सुधार जारी (R-Z<n>)" = सुधार अभी बन रहा है); असमर्थित = पहुँच संभव है पर बना नहीं; पहुँच से बाहर = ऐसी क्षमता चाहिए जो केवल आधिकारिक ऐप में है।
- **पहुँच**: API = नेटवर्क की आधिकारिक API (जहाँ पता हैं, एंडपॉइंट सहित); वेब = ब्राउज़र में नेटवर्क का वेब ऐप, विकल्प के रूप में (R-Y38); आर्काइव = नेटवर्क के डेटा एक्सपोर्ट का आयात; API + वेब = पहले API, और जब API में ऐसी कॉल न हो या मना करे तो वेब ऐप; पहुँच से बाहर = ऐसी क्षमता चाहिए जो केवल आधिकारिक ऐप में है।
- **आवश्यकताएँ**: [`REQUIREMENTS.hi.md`](../REQUIREMENTS.hi.md) के R-ID जो इस फ़ीचर को पूरा करते हैं।
- **सत्यापन**: यहाँ सब कुछ main के कोड और नकली (fake) परीक्षण-प्रतिरूपों के विरुद्ध जाँचा गया है। कुछ भी असली खाते पर सत्यापित नहीं है। टिप्पणियों में "योजना (R-Z<n>)" का अर्थ बाद का काम है, अभी चल नहीं रहा।

## ज्ञात कमियाँ

1. LinkedIn चैट को संदेश अब सार्वजनिक फ़ीड पोस्ट नहीं बनता, और प्रोफ़ाइल या रिज़्यूमे सिंक `shareAsPost` दिए बिना `unsupported` देता है (सुधार हुआ, R-Z4)। LinkedIn को संदेश वेब ऐप से जाते हैं, जो असली साइट पर अपरीक्षित है।
2. संदेश केवल ब्राउज़र रास्ते से हैं और उसके सेलेक्टर असत्यापित हैं; LinkedIn स्वचालित खाते को प्रतिबंधित कर सकता है।
3. आर्काइव आयात `messages.csv` पूरा पढ़ता है (R-Z10); Connections, Shares और Profile फ़ाइलें अब भी आयात नहीं होतीं (योजना, R-Z10)।
4. प्रोफ़ाइल लिखना केवल हेडलाइन, About और कौशल तक है; स्थान, अनुभव और शिक्षा नहीं लिखे जाते।
5. API से पोस्ट जीवनचक्र न्यूनतम है: पोस्ट id, संपादन, हटाना, मीडिया या केवल-कनेक्शन दृश्यता नहीं; लेखक URN हाथ से लिखना पड़ता है।
6. अपनी पोस्ट पढ़ने के लिए `r_member_social` पर LinkedIn की स्वीकृति चाहिए।
7. संपर्क और कनेक्शन आयात नहीं होते।
8. कम प्राथमिकता: रीशेयर, टिप्पणियाँ, Pages, पोल, शेड्यूलिंग।
