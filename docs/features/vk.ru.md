# VK матрица функций (languages: [en](vk.md) • [zh](vk.zh.md) • [hi](vk.hi.md) • ru)

Назад к [матрице функций Telegram](../FEATURES.ru.md). Эта страница только про VK.

## Объём и доступ

Объём — личный аккаунт VK. Ничто здесь не проверено на настоящем аккаунте VK: все тесты используют подделки, а веб-селекторы — непроверенные догадки. Сведения о самом VK взяты из исследования в репозитории (`docs/case-studies/issue-32/README.md`) и опубликованной документации VK; если деталь VK не удалось перепроверить, это сказано в примечаниях.

Есть три пути.

1. **Официальный API (`api.vk.ru/method/*`).** Авторизация — токен доступа, который вставляет пользователь (`VK_ACCESS_TOKEN` или сохранённый секрет). Жёсткие ограничения:
   - С 2024-06-25 VK больше не выдаёт новым приложениям пользовательское право `messages`, а implicit flow для пользовательских токенов закрыт. Это право было только у старых токенов (Kate Mobile, VK Admin), и их отключили. Токены веб-клиента vk.com (id 6287487) и VK Calls (7793118), по сообщениям, ещё работают — на риск собственного аккаунта пользователя (сообщают о заморозках от 24 часов до 4 дней).
   - **Токен сообщества** работает только в диалогах этого сообщества. Он не может читать личные чаты пользователя; список участников, друзья и набор текста частично неприменимы (ошибка 27).
   - Каждый метод работы с сообщениями (`messages.getConversations`, `getHistory`, `send`, `edit`, `delete`, `markAsRead`, `sendReaction`, `getLongPollServer`, загрузка фото и документов) требует права `messages` (и `photos` / `docs`); пользовательский токен без него получает ошибку 7 или 15.
   - Документация: https://dev.vk.ru/ru/api/access-token/getting-started , https://dev.vk.ru/ru/reference/access-rights , https://dev.vk.ru/ru/reference/errors , https://dev.vk.com/en/method/messages .
2. **Веб-приложение (vk.com/im) в собственном профиле браузера пользователя.** Единственный путь, который работает без токена `messages`: пользователь один раз входит в профиль. Селекторы охватывают два поколения интерфейса VK и не проверены на живом vk.com.
3. **Архив выгрузки данных** (https://vk.com/data_protection?section=rules). Импорт читает JSON-формат konard/vk-export (`conversations[].messages[]`). Собственная выгрузка VK — HTML, для которого пока нет разборщика (запланировано, R-Z8).

**Недоступно** (только официальное приложение или закрыто VK для сторонних): голосовые и видеозвонки, переводы VK Pay, мини-приложения и VK Play внутри чатов, сквозные (секретные) чаты VK Messenger, вход по passkey через VK ID, покупка стикеров и VK Donut, перевод сообщений, просмотр клипов и историй внутри чата, доставка push-уведомлений и API музыки (`audio.*`, закрыт для сторонних с 2016/2018).

Пока ничто здесь не держит VK «живым»: никакой планировщик не подтягивает сообщения VK и нет клиента Long Poll, поэтому вошедший аккаунт VK сам в чате не обновляется (запланировано, R-Z8).

## Обозначения

- **Статус**: Поддерживается = работает от начала до конца в приложении пользователя; Частично = работает с ограничением из примечания («исправляется (R-Z<n>)» = исправление делается сейчас); Не поддерживается = не сделано, хотя доступ возможен; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Доступ**: API = официальный API сети (эндпоинты названы, где известны); Веб = веб-приложение сети в браузере, как запасной путь (R-Y38); Архив = импорт выгрузки данных сети; API + Веб = сначала API, веб-приложение — когда в API нет такого вызова или он отказывает; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Требования**: R-ID из [`REQUIREMENTS.ru.md`](../REQUIREMENTS.ru.md), которые это реализуют.
- **Проверка**: всё здесь сверено с кодом в main и с подделками (fake). Ничто не проверено на настоящем аккаунте. «Запланировано (R-Z<n>)» в примечаниях означает будущую работу, сейчас она не ведётся.

## Известные пробелы

1. VK не «живой»: нет планировщика, нет кнопки выгрузки на странице, нет Long Poll (запланировано, R-Z8).
2. Список чатов содержит только последнее сообщение каждого чата, имена пусты, история не подгружается страницами (запланировано, R-Z8).
3. Медиа нельзя просмотреть: только первое вложение, фото показаны как имена файлов, политика страницы блокирует CDN картинок VK, URL протухают (запланировано, R-Z8).
4. Официальную HTML-выгрузку данных VK нельзя импортировать, хотя это единственный путь, работающий для всех, раз токены `messages` закрыты (запланировано, R-Z8).
5. Реакции показываются сырыми числами, а таблица эмодзи, скорее всего, неверна (запланировано, R-Z8).
6. Отправка — только текст и стикеры: без ответов, фото, файлов и голоса; `random_id` не детерминирован (запланировано, R-Z8). Неоднозначный сбой API больше не переключает на браузер (исправлено, R-Z4).
7. Веб-запасной путь не проверен на актуальном vk.com.
8. Получение токена — слабое место после отключения Kate Mobile; страница не предлагает пошагового сценария.
9. Ниже по приоритету: обнаружение удалённых сообщений (запланировано, R-Z7), друзья и карточки профилей, администрирование чатов, методы поиска, истории, стена, клавиатуры ботов.
