# Facebook (Messenger и Instagram) матрица функций (languages: [en](facebook.md) • [zh](facebook.zh.md) • [hi](facebook.hi.md) • ru)

Назад к [матрице функций Telegram](../FEATURES.ru.md). Эта страница только про Facebook (Messenger и Instagram).

## Объём и доступ

Объём — личный аккаунт Facebook (Messenger) и, отдельной группой строк в конце, Instagram Direct. Ничто здесь не проверено на настоящем аккаунте Facebook или Instagram: все тесты используют подделки, а веб-селекторы — непроверенные догадки (сам код об этом говорит).

Для личного аккаунта есть три пути. Только третий работает для живых сообщений личного ящика, и он не проверен на настоящей разметке.

1. **Официальный API (Graph API / Messenger Platform).** Адаптер использует `https://graph.facebook.com/v22.0` с токеном доступа _Страницы_ и id Страницы. Messenger Platform обслуживает только Страницы: входящие Страницы, webhook, 24-часовое стандартное окно сообщений и App Review (`pages_messaging`) для всех, кроме ролей приложения. **API для личного ящика Messenger нет** (прежнее разрешение `read_mailbox` и Chat API исчезли). Адаптер полезен только тому, кто ведёт Страницу. Документация: https://developers.facebook.com/docs/messenger-platform/ , https://developers.facebook.com/docs/graph-api/reference/page/conversations/ , https://developers.facebook.com/docs/messenger-platform/send-messages/ .
2. **Архив «Скачать вашу информацию».** Импорт читает один `message_N.json` за вызов. Рецепт автоимпорта открывает страницу «Скачать вашу информацию» в Центре аккаунтов; страница «Подключения» принимает `.json` и `.zip`. Архив — разовый снимок: чаты со сквозным шифрованием в обычный экспорт не входят (Meta предлагает их отдельно), и новые сообщения не приходят. Документация: https://www.facebook.com/help/212802592074644 .
3. **Веб-приложение в браузере.** Приложение управляет `https://www.facebook.com/messages/` в постоянном профиле автоматизации: отправка, чтение последних сообщений и списка чатов, правка, отмена отправки, реакции, пересылка. `messenger.com` не используется; обслуживает ли он ещё полноценный веб-клиент в 2026 году, неясно, так как Meta переносит его в `facebook.com/messages`.

**Instagram Direct.** В приложении пока ничего нет: ни источника Instagram, ни веб-записи, ни рецепта архива, ни руководства по подключению (запланировано, R-Z10: импорт архива Instagram). Официальные пути: Instagram Messaging API обслуживает только бизнес-аккаунты и аккаунты авторов, связанные со Страницей, но не личные (https://developers.facebook.com/docs/instagram-platform/instagram-api-with-facebook-login/messaging-api/ ). Личный ящик доступен через архив «Скачать вашу информацию» (тот же формат `message_1.json`, что у Facebook) и через `instagram.com/direct/` в браузере.

**Недоступно:** голосовые и видеозвонки, комнаты, чаты со сквозным шифрованием без PIN восстановления пользователя в веб-приложении (ввод PIN требует пользователя), функции Messenger только в мобильных приложениях (Chat Heads, AR-эффекты, платежи) и любые вызовы API личного ящика (их нет).

## Обозначения

- **Статус**: Поддерживается = работает от начала до конца в приложении пользователя; Частично = работает с ограничением из примечания («исправляется (R-Z<n>)» = исправление делается сейчас); Не поддерживается = не сделано, хотя доступ возможен; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Доступ**: API = официальный API сети (эндпоинты названы, где известны); Веб = веб-приложение сети в браузере, как запасной путь (R-Y38); Архив = импорт выгрузки данных сети; API + Веб = сначала API, веб-приложение — когда в API нет такого вызова или он отказывает; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Требования**: R-ID из [`REQUIREMENTS.ru.md`](../REQUIREMENTS.ru.md), которые это реализуют.
- **Проверка**: всё здесь сверено с кодом в main и с подделками (fake). Ничто не проверено на настоящем аккаунте. «Запланировано (R-Z<n>)» в примечаниях означает будущую работу, сейчас она не ведётся.

## Известные пробелы

1. Чтение личного ящика в веб-приложении скудно и не проверено: нет отправителя / направления, 5 чатов за выгрузку, нет id сообщений, на настоящей разметке Messenger не проверялось.
2. Разборщик архива теряет данные и может портить id: id в одну миллисекунду совпадают, кракозябры в нелатинском тексте, вложения, реакции и тип треда отбрасываются (запланировано, R-Z10).
3. Id чатов из архива не совпадают с числовым id треда, нужным вебу, поэтому ответ из импортированного треда не удаётся (запланировано, R-Z10).
4. Страница «Подключения» сначала предлагает форму токена Страницы, а личному пользователю нужны архив (история) и браузер с выполненным входом (живое); формулировки должны это сказать (документация, R-Z13).
5. Часть кода API Страницы не доказана или мертва: разборщик квитанций доставки никто не вызывает (R-Z7), у webhook нет маршрута, синхронизация профиля не проверена, отправка не умеет вкладывать файлы и отвечать.
6. В веб-отправке нет стикеров, вложений, ответов, темпа, а селекторы охватывают только английский и русский. Неоднозначный сбой отправки больше не повторяется (исправлено, R-Z4).
7. Instagram Direct отсутствует; путь через архив — дешёвый первый шаг (запланировано, R-Z10).
8. Ниже по приоритету: реакции, пересылки, список друзей, метаданные групп и запросы на переписку читаются из архива или веба, но отбрасываются.
