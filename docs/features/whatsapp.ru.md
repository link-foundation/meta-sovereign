# WhatsApp матрица функций (languages: [en](whatsapp.md) • [zh](whatsapp.zh.md) • [hi](whatsapp.hi.md) • ru)

Назад к [матрице функций Telegram](../FEATURES.ru.md). Эта страница только про WhatsApp.

## Объём и доступ

Объём — личный аккаунт WhatsApp пользователя. Ничто здесь не проверено на настоящем аккаунте WhatsApp: все тесты используют подделки, ни один тест не касается настоящей страницы WhatsApp Web, а селекторы WhatsApp Web — непроверенные догадки (сам код говорит, что без аккаунта с выполненным входом их проверить нельзя). Сведения о WhatsApp взяты из кода и официальных страниц ниже; точные лимиты экспорта не перепроверялись.

Есть три пути; для личного номера работают только два.

| Путь                                           | Что делает                                                                                                                                                   | Работает для личного аккаунта?                                                                                                                                                                                                                                                                                                         |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| WhatsApp Cloud API (Graph API `v22.0`)         | Отправка текста и стикеров, отметка прочтения, набор, реакции, обновление бизнес-профиля; входящие — только разбором webhook-данных, которые кто-то передал. | Нет. Cloud API обслуживает только номера WhatsApp Business Platform (зарегистрированные в API, с приложением Meta, бизнес-портфолио, токеном и id номера телефона). Вне 24-часового окна обслуживания клиента можно слать только одобренные шаблоны. Документация: https://developers.facebook.com/docs/whatsapp/cloud-api/get-started |
| Архив экспорта чата (`_chat.txt`)              | Импортируется из поля импорта в настройках и автоимпортом.                                                                                                   | Импортируется из поля импорта в настройках (`.txt` или `.zip` с медиа) и автоимпортом. Читаются форматы Android и iOS (R-Z9).                                                                                                                                                                                                          |
| WhatsApp Web в браузере (связанное устройство) | Отправка, набор, чтение последних сообщений и списка чатов, правка, удаление, реакции, пересылка, отметка прочтения, захват страницы.                        | Отправка, набор, чтение последних сообщений и списка чатов, правка, удаление, реакции, пересылка, отметка прочтения, захват страницы. Через него уходит только сообщение, которое вы подтвердили сами (R-Z9).                                                                                                                          |

**Недоступно:** любые функции только официального приложения: звонки с номера телефона, WhatsApp Pay, резервное копирование и восстановление чатов, адресная книга телефона, PIN блокировки чата, сквозное шифрование резервных копий, смена номера телефона, регистрация и удаление аккаунта за пределами Web. Официального API для личного аккаунта нет. Неофициальные библиотеки (Baileys, whatsapp-web.js) не рассматривались: это сторонний код и нарушение условий WhatsApp.

**Условия использования:** условия WhatsApp запрещают автоматические и массовые сообщения и неофициальные клиенты. Карточка WhatsApp в «Подключениях» теперь говорит об этом, и приложение так и действует: в WhatsApp Web набирается только сообщение, которое вы подтвердили сами; приветствия, правила, рассылка и пакетное возвращение в личный WhatsApp не пишут никогда (они отклоняются с `unsupported`). Meta всё равно может ограничить номер, которым пользуются через Web (R-Z9).

Коротко: приложение умеет через WhatsApp Web читать список чатов, видимую историю одного чата, отправлять подтверждённое вами сообщение, набирать, править, удалять, ставить реакции, пересылать и отмечать прочитанным, а войти в профиль отправителя пользователь теперь может (видимое окно, QR сканирует он сам). Селекторы по-прежнему непроверенные догадки. У чатов из Web и архивов устойчивые id. В группы отправлять по-прежнему нельзя.

## Обозначения

- **Статус**: Поддерживается = работает от начала до конца в приложении пользователя; Частично = работает с ограничением из примечания («исправляется (R-Z<n>)» = исправление делается сейчас); Не поддерживается = не сделано, хотя доступ возможен; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Доступ**: API = официальный API сети (эндпоинты названы, где известны); Веб = веб-приложение сети в браузере, как запасной путь (R-Y38); Архив = импорт выгрузки данных сети; API + Веб = сначала API, веб-приложение — когда в API нет такого вызова или он отказывает; Недоступно = нужна возможность, которая есть только у официальных приложений.
- **Требования**: R-ID из [`REQUIREMENTS.ru.md`](../REQUIREMENTS.ru.md), которые это реализуют.
- **Проверка**: всё здесь сверено с кодом в main и с подделками (fake). Ничто не проверено на настоящем аккаунте. «Запланировано (R-Z<n>)» в примечаниях означает будущую работу, сейчас она не ведётся.

## Известные пробелы

1. Личный пользователь может войти в WhatsApp Web действием «Войти в WhatsApp Web» (видимое окно, QR сканирует он сам); на настоящем аккаунте WhatsApp ничего не запускалось (исправлено, R-Z9).
2. Идентичность чата: у сообщений Web и архивов устойчивые id (номер в E.164, JID группы; хэш названия чата — только для архивов, где имя файла — имя контакта), но чтение списка чатов по-прежнему ключуется заголовком, а архив чата с именем контакта не сопоставляется с тем же человеком в Web (исправлено частично, R-Z9).
3. Id сообщений устойчивы (шаблон id группы исправлен, id архивов детерминированы); даты Web по локали по-прежнему не разбираются, а время в архиве без часового пояса (исправлено частично, R-Z9).
4. Импортёр архивов читает форматы Android и iOS, многострочные сообщения, системные строки и имена медиа, `.txt` и `.zip` (исправлено, R-Z9).
5. Селекторы WhatsApp Web ни разу не проверялись на живой странице.
6. Чтение из Web — только текст и только видимые строки: без ответов, реакций, медиа и подгрузки истории вверх.
7. Приветствия идут через Cloud API даже для личного аккаунта и явно не удаются без его учётных данных; 24-часовое окно больше не пропускает давних контактов ошибочно (исправлено, R-Z3).
8. Предупреждение об условиях и честный путь входа есть на карточке WhatsApp; в руководстве по подключению Cloud API по-прежнему первый (исправлено частично, R-Z9).
9. Ниже по приоритету: фоновый опрос и уведомления, приёмник webhook Cloud API и медиа для бизнес-пользователей, отправка медиа / голоса / файлов, администрирование групп, Статус, каналы, опросы, просмотр контактов, несколько аккаунтов.
