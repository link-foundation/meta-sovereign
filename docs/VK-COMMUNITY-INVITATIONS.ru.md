# Приглашения в сообщества ВКонтакте (languages: [en](VK-COMMUNITY-INVITATIONS.md) • ru • [hi](VK-COMMUNITY-INVITATIONS.hi.md) • [zh](VK-COMMUNITY-INVITATIONS.zh.md))

Откройте **Подключения → ВКонтакте → Вручную → Приглашения в сообщества**. Расписание, замена записей и аватар изначально выключены. Задайте положительные ID сообществ, варианты текста по строкам и метку, присутствующую в каждом варианте. Личные адреса из исходных проектов не используются по умолчанию.

Можно выбрать до десяти исходных ID фото, аудио, видео или документов с необязательным ключом доступа. URL и загрузка файлов здесь не поддерживаются. Аватар берётся из текущего профиля без повторной загрузки. Сообщества с ограничениями получают отдельный текст без заданных медиа; явно включённый аватар сохраняется. Если есть другой вариант текста, предыдущий не повторяется.

Включите случайный выбор одного заданного медиа, чтобы каждая новая проверка выбирала один элемент из списка. Точный выбор виден до подтверждения и сохраняется при отправке и частичном восстановлении. Аватар добавляется отдельно; в ограниченных сообществах список медиа пропускается. Если опция выключена, прикрепляются все заданные элементы. CLI: `--random-attachment true` (выключить: `false`); API и офлайн: `randomAttachment`.

Сохраните настройки и проверьте сообщество, точный текст, вложения и ID своих старых записей. Публикация удерживается при наличии своего приглашения среди десяти верхних записей, в период ожидания, при защите сообщества, отзыве согласия или неполных данных. Нулевой лимит ничего не публикует. Для замены нужен полный ограниченный поиск до 1000 совпадений; удаляются только неизменённые записи текущего аккаунта с правом удаления.

Подтвердите актуальную проверку. Сначала надёжно сохраняется положительное подтверждение новой записи, затем отдельно проверяется и подтверждается каждое удаление. При частичной замене нужна новая ручная проверка; продолжаются только оставшиеся удаления без повторной публикации. Неизвестный результат публикации или удаления автоматически не повторяется. Коды ВКонтакте 15/210/219 приостанавливают сообщество на сутки; они, а также 10/14, приостанавливают приглашения аккаунта минимум на минуту.

CLI: `meta-sovereign vk-wall save`, `plan`, `run --plan <id> --confirm`. API: `/api/vk/wall` с текстовым или двоичным Lino. Настраиваются `--communities`, `--messages`, `--marker`, `--attachments`, `--restricted-communities`, `--restricted-message`, `--replace-owned`, `--active-avatar`, `--limit`, `--cooldown-days`, `--every-minutes`. В браузере настройки сохраняются без сервера; для проверки и отправки нужны локальный сервер и аккаунт ВКонтакте. Сервер владеет расписанием и завершает работу при остановке.

Опция удержания при приглашении любого автора среди верхних десяти записей изначально выключена; по умолчанию учитываются свои приглашения. CLI: `--hold-any-visible true`; API и офлайн: `holdAnyVisible`.

Если успешная текущая проверка ВКонтакте подтверждает отсутствие старой проверенной записи, замена продолжится для оставшихся. ID отсутствующих записей показаны отдельно от подтверждённых удалений. Одного отказа 100/104 недостаточно; неизвестная запись остаётся неизвестной. Возвращение отсутствовавшей записи после проверки требует новой проверки. Новая подтверждённая запись должна оставаться неизменной.

Исходный скрипт приглашений друзьям также публикует на стенах настроенных сообществ. [Разбор исходника](case-studies/issue-56/vk-friend-invitations.md) и [проверки](case-studies/issue-56/vk-wall.md).
