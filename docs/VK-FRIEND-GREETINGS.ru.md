# Приветствия друзьям ВКонтакте (языки: [en](VK-FRIEND-GREETINGS.md) • ru • [hi](VK-FRIEND-GREETINGS.hi.md) • [zh](VK-FRIEND-GREETINGS.zh.md))

Откройте **Подключения → ВКонтакте → Ввести вручную → Приветствия друзьям ВКонтакте**. Сервис проверяет текущую дружбу через настроенные личные учётные данные VK API. Без сервера можно редактировать настройки, но нельзя проверять состояние или отправлять сообщения через VK. Автоматическое расписание изначально выключено, фильтр «только онлайн» включён.

Выберите текст приветствия или ID стикера VK. Ненулевой ID заменяет текст стикером. Настройте минимальную тишину в беседе, паузу для каждого человека, число проверяемых друзей и предел отправок. Ноль отправок исключает действия. Можно выбирать только пустые беседы или отключить фильтр онлайн. Сначала идут пустые беседы, затем самые старые; дополнительная сортировка по общему числу друзей имеет приоритет. Приоритетные ID и общий список отказов от сообщений всегда защищают соответствующие аккаунты.

Сохраните настройки и нажмите **Проверить текущее состояние**, чтобы увидеть точное содержимое и основания допуска. Подтверждение относится только к просмотренному плану, действующему пять минут. Непосредственно перед каждой отправкой должны по-прежнему совпадать дружба, онлайн, непрочитанность, разрешение писать, полная ограниченная история и аккаунт. Непрочитанные беседы, служебные события, недоступная или частичная история и неопределённые отправки блокируют действие. История свыше 1000 сообщений пропускается, а не оценивается по последним сообщениям. Пакет ограничен 100 приветствиями и проверкой 10 000 друзей; между действиями проходит 30 секунд.

Если включить расписание, локальный сервер приложения проверяет сохранённый интервал раз в минуту и управляет работой до завершения. Для автоматических отправок действуют тихие часы. Закрытие сервера прекращает новые действия и прерывает ожидание между отправками. Ручное подтверждение не включает расписание.

CLI использует те же настройки и постоянное хранилище:

```sh
meta-sovereign vk-greet status
meta-sovereign vk-greet save --message="Привет!" --limit=3 --online-only=true --stale-days=30 --cooldown-days=7
meta-sovereign vk-greet plan
meta-sovereign vk-greet run --plan=THE_REVIEWED_PLAN_ID --confirm
```

Локальный API: `/api/vk/greet`, действия `/plan` и `/run`. Поддерживаются стандартные текстовый и бинарный форматы Lino, проверка источника записи и явное подтверждение плана. Внешний запрос не может выдавать себя за запуск расписания.

Только положительная квитанция с собственным ID сообщения VK считается подтверждением. Такие приветствия появляются в Чате с фактическим ID VK; стикеры сохраняют собственный ID. Потерянная или недействительная квитанция означает неизвестный результат без автоматического повтора после обновления или перезапуска. Явный отказ отличается от неопределённой доставки. Новое приветствие требует нового просмотра и истечения обоих сохранённых сроков: тишины и паузы.
