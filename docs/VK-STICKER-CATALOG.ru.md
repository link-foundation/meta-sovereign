# Каталог стикеров VK

В Подключения → VK откройте каталог стикеров и укажите ID подключённого
аккаунта. Просмотр читает сохранённый снимок без обращения к VK. Явное
обновление получает купленные активные наборы, ключевые слова и наборы
приветствий. Доступность требует купленного активного набора и явного
разрешения стикера; будущая отправка всё равно может быть отклонена.

Используйте поиск, ID набора, категорию и страницы по 100 результатов.
Сохраняются все ID доступных приветствий одного набора. Ошибки, неполные
ответы и смена аккаунта сохраняют предыдущий подтверждённый снимок.
В разделе Стикеры выберите коллекцию VK, переключите нужный стикер и
нажмите Сохранить. Выбор сохраняется после перезагрузки.

Фильтр полученных вложений принимает JSON объект или массив, оставляет
положительные ID стикеров/продуктов и перечисляет уникальные продукты.
Получение не подтверждает право отправки. Фильтр работает автономно.

Экспорт сохраняет наборы, доступные стикеры, ключевые слова, ID приветствий,
текущую выборку и необязательные полученные ID частями JSON до 1500 строк.
Укажите новую абсолютную папку компьютера сервера вне хранилища приложения;
родительская папка должна существовать. Существующие пути отклоняются.
Ссылки предпросмотра сохраняются, изображения не скачиваются. Манифест
создаётся после успеха всех частей. После ошибки проверьте частичные файлы
и повторите в новой папке. Обновление ничего не покупает и не отправляет.

Команды, флаги и Lino API приведены в [полном руководстве](VK-STICKER-CATALOG.md).
Просмотр и фильтр доступны автономно; обновление и экспорт требуют сервера.
