# Сохранённые анкеты

Чаты, ответы в откликах и внешние формы используют общий планировщик. При чтении
актуальных правил он индексирует согласованные нумерованные ответы из сохранённых
полных анкет. Условия, инструкции и код остаются при родительском вопросе.
Неоднозначные пары не разделяются; полный сохранённый ответ имеет приоритет.

Извлечённая часть требует проверки даже после одобрения полного ответа.
Ограничения по сервису и чату, исправления, актуальные зарплатные и контактные
данные сохраняются. Чтение не записывает правила и ничего не отправляет.
Новая сборка анкеты также требует проверки.

Заполнение нативного отклика и автоматическая отправка точных ответов также
требуют одобренного однозначного сохранённого ответа. Извлечённые,
неодобренные или конфликтующие ответы остаются для проверки владельцем, даже
если текст поля совпадает. Владелец может заполнить форму и отдельно подтвердить отправку.

В разделе **Вопросы и сохранённые ответы → Изучить разговоры** можно посмотреть
части сохранённых анкет вместе с ответами из архива и сохранить предложения для
проверки. Сохранённая формулировка добавляет ноль использований; частоты берутся
только из реально отправленных ответов. Повторный запуск не пересчитывает те же
наблюдения и сохраняет одобрения. История из сервисов не загружается.

Офлайн-команды:

```sh
meta-sovereign automations answers backfill-questionnaires
meta-sovereign automations answers backfill-questionnaires --apply
```

`answers learn` включает ту же операцию. Оба формата Links Notation поддерживают
`POST /api/automations/answers/backfill-questionnaires` и `/api/automations/answers/learn`.
`apply: false` только показывает предложения; `apply: true` сохраняет их.
Отказ из-за ёмкости или изменения правил не применяет предложения: сначала
запросите новый предпросмотр.

## Контекст нативного отклика

Перед запуском отдельного отклика или пакета в CV выберите общий профиль и
задайте зарплатные цели в настройках отклика. Каждая часть анкеты использует
свою валюту, сумму до или после налогов и нужный контакт. Квитанция показывает
подтверждённый профиль и зафиксированные цели. Каждый новый план читает
актуальные значения сохранённого профиля; изменение контактов не меняет
зарплатные цели. Если профиль удалён, планирование отклоняется. Составные
ответы требуют проверки и не запускают автоматическую отправку точных ответов.

CLI отдельного и пакетного отклика принимает `--profile-id` и `--salary`
(запись Links Notation с общей конфигурацией зарплаты). API открытия отклика и
запуска пакета принимает `profileId` и `salary` в обоих форматах Lino. Без этих
полей сохраняется прежнее поведение. В браузере для восстановления хранится
только идентификатор отклика.
