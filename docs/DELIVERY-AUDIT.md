These are behavioral checks, not a promise that every external service request succeeds. Telegram rate limits still delay downloads; a disconnected browser does not imply that its server died. Numeric-only Telegram contacts require a separate Telegram Web sign-in because native clients provide no portable numeric-user chat link. Initial work-account support does not imply complete messaging/job synchronization for all four services. iCloud contacts are imported from the system address book or a vCard, rather than by collecting an iCloud password.

Successful foreground history completion also clears stale failure/retry markers from a concurrent scroll request. The rate-limit recovery browser check verifies that a fully loaded short conversation does not retain a misleading connection-interrupted marker.

Local regression tests use temporary stores and fake service responses. Automated message sends and read acknowledgements target fixtures, never personal conversations. Live diagnostics check server identity, account/health state and transport without sending messages. The Windows migration retry also retains the original writer-lock and rollback protections.
