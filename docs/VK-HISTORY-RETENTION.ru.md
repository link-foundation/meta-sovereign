# Очистка истории ВКонтакте

Откройте Подключения → ВКонтакте → Очистка истории. Расписание изначально выключено. Задайте ID бесед, строгий порог числа сообщений и предел проверки выше порога. Допустимы отрицательные ID и ID групповых бесед. Защищённые абсолютные ID и глобальный список отказов исключаются.

Проверка показывает аккаунт, выбранные беседы, число сообщений провайдера и совпавших локальных записей, сохранённые подтверждения удаления. Подтверждайте только показанный план. Изменение настроек, ключа, аккаунта, истории, локального содержимого или истечение срока отменяет выполнение. История сверх предела проверки не удаляется.

Текущий метод messages.deleteConversation удаляет историю только для этого аккаунта. Только явная ошибка ВКонтакте 3 разрешает переход к messages.delete с проверенными cmids и delete_for_all=0: до 100 сообщений в пакете, пауза две секунды. Тайм-аут, потерянный ответ или неверное подтверждение не разрешают запасной метод или автоповтор. Перед локальной очисткой результат подтверждается чтением истории.

Частичное выполнение сохраняет подтверждённые ID и квитанции. После перезапуска проверьте вручную только остаток исходных сообщений; расписание не продолжает частичную очистку. Локальные записи сопоставляются по ID, беседе, тексту и времени. Содержимое сохраняется под восстанавливаемой отметкой удаления и синхронизируется с причинными метаданными. Другие провайдеры и непроверенные записи не затрагиваются. Физического удаления нет.

CLI в переднем плане:

```sh
meta-sovereign vk-retention save --peers=9,-12 --threshold=1000 --scan-limit=2000 --enabled=false
meta-sovereign vk-retention plan
meta-sovereign vk-retention run --plan=<reviewed-plan-id> --confirm=true
meta-sovereign vk-retention status
```

`/api/vk/retention` · `POST /plan` · `POST /run` · Lino text / binary.
