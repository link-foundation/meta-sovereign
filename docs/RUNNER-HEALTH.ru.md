# Проверка приложения (языки: [en](RUNNER-HEALTH.md) • ru • [hi](RUNNER-HEALTH.hi.md) • [zh](RUNNER-HEALTH.zh.md))

Откройте **Настройки → Сеансы выполнения → Показать управление сеансами →
Проверить приложение**. Состояние сеанса и последняя проверка приложения —
отдельные наблюдения. Открытие панели не проверяет приложение. Закрытие отменяет
принадлежащий панели запрос и игнорирует поздний ответ. Новое действие или
изменение наблюдаемого состояния сеанса очищает последнюю проверку. Проверка
ничего не устанавливает, не запускает и не останавливает.

```sh
meta-sovereign runner inspect local --profile=/absolute/path/runner.lino
meta-sovereign runner inspect server --url=http://127.0.0.1:8787
meta-sovereign runner health --store=/absolute/path/store
```

`inspect` обращается к настроенному узлу, в том числе через SSH. После изменения
профиля сохранённый работающий или непроверенный узел остаётся доступен;
проверка не разрешает запуск нового узла. Для остановленного или ненастроенного
сеанса команда приложения не выполняется. `health` читает частный канал
работающего узла выбранного хранилища, не открывая хранилище и профиль. Нужен
rolling-сервер этой версии. Старый или отсутствующий узел даёт `unknown`;
посторонний сервис на публичном порту не подтверждает готовность.

`GET /api/runner/inspect?mode=local` (или `mode=server`) использует тот же
запрос, стандартный текстовый/двоичный Links Notation и прежние правила кода
доступа и origin. CLI и API выбирают настроенный режим, а не произвольный путь.

Результаты: `ready`, `locked`, `degraded`, `unknown`. `ready` подтверждает ответ
принадлежащего узлу рабочего процесса со состоянием хранилища, но не включённые
задачи и доставку. `locked` требует разблокировки защищённых функций;
`degraded` сообщает о проблеме хранилища. `unknown` включает отмену, запуск или
смену процесса, недоступный канал, неверный ответ и ошибку транспорта. Нулевой
код `runner health` подтверждает чтение `ready`, `locked` или `degraded`.
`inspect` также даёт ноль для подтверждённого остановленного/ненастроенного
сеанса без запроса приложения. Это не подтверждает успех задачи.

Запрос рабочего процесса ограничен двумя секундами и 16 КиБ ответа; частный
канал — 2,5 секунды. Настроенная команда ограничена десятью секундами,
отменяет свой транспорт и ждёт закрытия дочернего процесса до освобождения
контроллера. Ответ не содержит учётных данных и удалённой диагностики. Изменения
не повторяются автоматически.
