# Дорожная карта (languages: [en](ROADMAP.md) • [zh](ROADMAP.zh.md) • [hi](ROADMAP.hi.md) • ru)

## Для кого meta-sovereign

meta-sovereign представляет **человека или организацию в интернете**. Один владелец подключает аккаунты, через которые он общается, — Telegram, VK, WhatsApp, Facebook и Instagram, X, LinkedIn, почту, GitHub, Upwork, PeoplePerHour и сайты вакансий — и ведёт все разговоры в одном приложении на своём компьютере. Данные остаются его: локальное хранилище, зашифрованные резервные копии, без облака посередине.

Один и тот же inbox, контакты и автоматизации служат четырём видам работы:

- **Личное**: поддерживать связь с людьми, помнить, что было сказано, держать одно резюме везде.
- **Продажи**: находить и сегментировать лидов во всех сетях, писать каждому лично, но массово, делать follow-up, быстро отвечать.
- **Маркетинг**: рассылки по аудиториям, публикация постов, рост и знание сообществ.
- **Поддержка пользователей**: одна очередь для всех входящих, ответы от имени сообщества или бизнес-аккаунта, готовые ответы и база знаний из фактов.

Этот файл связывает каждый сценарий с его **критическими путями**: что работает сегодня, что частично и что дальше. Подробности по сетям — в [`FEATURES.ru.md`](./FEATURES.ru.md) и [`features/`](./features/); каждое требование и его подтверждение — в [`REQUIREMENTS.ru.md`](./REQUIREMENTS.ru.md).

## Как читать статус

- **Готово**: работает от начала до конца в приложении и покрыто тестами. Тесты используют подделки; только отображение сообщений Telegram дополнительно проверено, только чтением, на реальном хранилище (см. «Проверка» ниже).
- **Частично**: работает с ограничением, названным в строке.
- **Запланировано**: ещё не сделано; перечислено в «Дальше» по приоритету.
- **Невозможно**: нужно то, что есть только у официальных приложений, или публичный сервер, которого у локального приложения нет.

## Дальше, по приоритету

Ни у одного пункта нет даты; номер требования пункт получает, когда работа начинается.

1. **Проверка на живых аккаунтах.** Один раз пройти критические пути каждой сети на реальном аккаунте пользователя, при пользователе (пока проверено только отображение Telegram, только чтением). До этого строка означает «проверено с подделками».
2. **Вход с подсказками.** OAuth с обновлением для Gmail и Outlook.com, OAuth для X, device flow GitHub и пошаговое получение токена VK, чтобы никому не приходилось вставлять токен на один час.
3. **Входящие для бизнеса без вебхуков.** Загружать беседы Facebook Pages и сообщения WhatsApp Cloud API по расписанию, где API это позволяет; прямо говорить, где сработал бы только вебхук.
4. **Командный режим для организаций.** Несколько операторов на одном сервере, у каждого свой вход; назначить чат, внутренние заметки, кто ответил, роли.
5. **Воронка продаж.** Этапы у контактов, напоминания о follow-up и список «на сегодня», сумма сделки.
6. **Результаты кампаний и согласие.** Отчёт по каждой автоматизации и рассылке (отправлено, ответили, отписались, неизвестно), и ответы вроде «стоп» сами попадают в список отписавшихся.
7. **Богаче отправка.** Ответы, фото и файлы в VK, X и почте (вложения, копия в «Отправленных», подписи).
8. **Публикации.** Посты на стене VK, жизненный цикл поста LinkedIn (правка, удаление, медиа), посты X с медиа.
9. **Соискатели.** Входящие от рекрутеров на сайтах вакансий в браузере с выполненным входом, планы резюме, запущенные на реальных сайтах.

Только владелец, не приложение: публикация пакета в npm, проверка веб-селекторов на реальных аккаунтах пользователя.

## Проверка

Каждый критический путь покрыт тестами с подделками. Только отображение сообщений Telegram дополнительно проверено на реальном хранилище (только количества, только чтение); ни одна отправка не делалась с реального аккаунта. Поэтому «Готово» значит «работает по документированному API или веб-приложению», а не «видели работающим в реальной сети». Пункт 1 это закроет.
