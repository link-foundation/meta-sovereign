## 当前范围

当前的优先事项是完整显示私聊、群组和频道中的每一条消息。特殊功能暂缓，列在此处以便日后回来处理。只实现通过 API（MTProto，第 232 层，`telegram` 包）或浏览器中网络的网页应用可达的功能；只有官方应用能做到的标为“不可访问”。

目前没有正在进行的工作。搁置：R-Y213 至 R-Y219。

## 图例

- **状态**：已支持 = 可用；部分 = 可用但有备注中所述的限制（正在进行的工作也如此标注）；搁置 = 已开始，应用户要求停止，未完成的工作保存在 worktree 中；不支持 = 尚未构建。
- **访问方式**：API = MTProto 方法（已知时给出名称）；网页 = 浏览器中网络的网页应用，作为后备（R-Y38）；API + 网页 = 先用 API，API 没有该调用或被拒绝时用网页应用；不可访问 = 需要只有官方应用才具备的能力。
- **需求**：[`REQUIREMENTS.zh.md`](./REQUIREMENTS.zh.md) 中实现该功能的 R-Y 行，写明已完成内容和已知限制。
- **验证**：多数功能用假数据测试，除非备注说明，否则未对照真实 Telegram 检查。对真实存储的显示普查（仅计数）涵盖媒体 photo、document、webpage、poll、contact、dice、story、geo 以及 283 条 unsupported 消息，所有常见实体，以及 ChatJoinedByRequest、InviteToGroupCall、ChatEditPhoto、BoostApply、NewCreatorPending 等服务动作。
