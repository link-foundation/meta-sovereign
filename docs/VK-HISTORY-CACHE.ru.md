# История VK и кэш метаданных

Откройте Подключения → VK → История VK и кэш метаданных. Укажите ID подключённого
аккаунта, ID диалога и тип: история, диалог, друзья, профиль или число друзей.
Список друзей относится к аккаунту и игнорирует ID диалога. Профиль и число
друзей требуют положительный ID пользователя.

Просмотр читает сохранённые данные без VK. Загрузка получает до 200 записей на
страницу, 1–50 страниц за явный запрос. Неполная история продолжается с
подтверждённого смещения; изменение первой страницы требует перезапуска.
Загрузка полного кэша создаёт новый снимок. Ошибка не продвигает подтверждённый
курсор. Отправки сообщений и удаления данных VK нет.

Показаны число записей, общее число VK, смещение и время. Сроки: история —
30 дней, друзья — 14 дней, профиль — час, число друзей — 1080 дней; диалог —
без автоматического срока. Старые снимки и успешные пустые результаты остаются
доступны. Они не подтверждают текущее состояние VK.

Выберите новую абсолютную папку на компьютере сервера вне хранилища, с уже
существующим родителем. Существующие пути и ссылки отклоняются. Связанные части
Markdown и исходного JSON содержат до 1500 строк, сообщения от старых к новым,
UTC, ссылки авторов, цитаты и полные исходные записи. Медиа не скачиваются.
Манифест указывает неполноту и устаревание. При ошибке частичные файлы остаются
без подтверждения успеха; повторите в другой новой папке.

[CLI и Lino](VK-HISTORY-CACHE.md) используют тот же кэш. Без сервера доступен
локальный просмотр; загрузка и экспорт требуют сервера.
