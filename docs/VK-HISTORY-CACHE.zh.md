# VK 历史与元数据缓存

打开连接 → VK → VK 历史与元数据缓存。填写已连接的 VK 账户 ID、会话 ID，
选择历史、会话、好友列表、个人资料或好友数。好友列表属于所选账户，忽略会话
ID；个人资料和好友数需要正数用户 ID。

查看缓存只读取已保存数据。加载每页最多 200 条，每次明确请求读取 1–50 页。
不完整历史从已确认偏移量继续；VK 首页变化时需要重新开始。完整缓存再次加载
会建立新快照。失败不会推进已确认进度。缓存操作不会发送消息或删除 VK 数据。

面板显示缓存条数、VK 总数、下一偏移量和时间。有效期：历史 30 天、好友
14 天、资料一小时、好友数 1080 天；会话没有自动到期时间。过期快照及成功的
空结果仍可查看。缓存不能证明 VK 当前状态。

导出时选择服务器电脑上存储目录之外的新绝对路径，父目录必须已存在。已有
路径及符号链接会被拒绝。相互链接的 Markdown 和原始 JSON 分卷最多 1500 行，
按旧到新保留消息、UTC 时间、作者链接、回复引用及完整原始记录。不会下载
媒体。清单明确记录不完整或过期覆盖。失败时保留部分文件，不返回成功凭据；
请换一个新目录重试。

[CLI 和 Lino 命令](VK-HISTORY-CACHE.md) 使用相同缓存。离线可查看本地缓存；
加载和文件导出需要已连接服务器。
