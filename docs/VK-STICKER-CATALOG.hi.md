# VK स्टिकर कैटलॉग

कनेक्शन → VK में स्टिकर कैटलॉग खोलकर जुड़े खाते की ID दें। सहेजा कैटलॉग
देखना VK से संपर्क नहीं करता। स्पष्ट रिफ़्रेश खरीदे सक्रिय पैक, कीवर्ड और
अभिवादन पैक पढ़ता है। उपयोग योग्य के लिए खरीदा सक्रिय पैक और स्पष्ट
स्टिकर अनुमति चाहिए। सहेजी अनुमति स्नैपशॉट है; भविष्य का भेजना अस्वीकार
हो सकता है। अधूरा उत्तर, त्रुटि या खाता बदलने पर पिछला स्नैपशॉट रहता है।

शब्द या ID खोजें, पैक और श्रेणी चुनें तथा 100 परिणामों के पृष्ठ देखें।
एक पैक के सभी उपयोग योग्य अभिवादन ID रखे जाते हैं। स्टिकर स्क्रीन में
VK संग्रह चुनें, स्टिकर का चयन बदलें और सहेजें। चयन रीलोड के बाद रहता है।

प्राप्त अटैचमेंट का JSON ऑब्जेक्ट या सरणी छाँटकर सकारात्मक स्टिकर/उत्पाद
ID और अद्वितीय उत्पाद मिलते हैं। प्राप्त होना भेजने की अनुमति सिद्ध नहीं
करता। यह छँटाई ऑफ़लाइन भी चलती है।

निर्यात पैक, उपयोग योग्य स्टिकर, कीवर्ड, अभिवादन ID, वर्तमान चयन और
वैकल्पिक प्राप्त ID को अधिकतम 1500 पंक्तियों वाले JSON भागों में सहेजता
है। सर्वर कंप्यूटर का नया पूर्ण पथ दें, जो ऐप भंडार के बाहर हो और जिसका
मूल फ़ोल्डर मौजूद हो। मौजूदा पथ अस्वीकार होंगे। पूर्वावलोकन लिंक रहेंगे;
चित्र डाउनलोड नहीं होंगे। सभी भाग सफल होने पर मैनिफ़ेस्ट बनता है। त्रुटि
पर आंशिक फ़ाइलें देखें और नए फ़ोल्डर में दोहराएँ। रिफ़्रेश कुछ भेजता या
खरीदता नहीं है।

देखें। ऑफ़लाइन निरीक्षण और छँटाई उपलब्ध हैं; रिफ़्रेश और निर्यात को सर्वर चाहिए।
