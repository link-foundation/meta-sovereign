# VK उपयोगकर्ता टोकन

**Connections → VK** में अपना उपयोगकर्ता टोकन या ठीक
`https://oauth.vk.com/blank.html#…` वाला अंतिम पता डालें। डेस्कटॉप ऐप में
Kate Mobile से अनुमति लेने के लिए अलग सुरक्षित VK विंडो भी है। VK इस पुराने
क्लाइंट या संदेश अनुमति को अस्वीकार कर सकता है। लॉगिन पृष्ठ दिखना सफल अनुमति
या संदेश क्षमता का प्रमाण नहीं है।

JS सर्वर या डेस्कटॉप ऐप शुरू करने से पहले `MS_SECRET_PASSPHRASE` सेट करें;
[उपयोगकर्ता मार्गदर्शिका](USER-GUIDE.hi.md) में संग्रहीत रहस्यों की सुरक्षा पढ़ें।
हर बार वही पासफ़्रेज़ चाहिए। सुरक्षित संग्रह के बिना यह सुविधा टोकन सहेजने से
मना करती है। इस सेटिंग से बाकी डेटाबेस एन्क्रिप्ट नहीं होता।

हर प्रयास के लिए बदलने की सहमति अलग दें। जाँच केवल प्रोफ़ाइल, अनुमतियाँ और
एक बातचीत सूची का काउंटर पढ़ती है; संदेश नहीं भेजती। वैध उपयोगकर्ता टोकन
सुरक्षित `secret:vk:user-token` में सहेजा जाता है, जिसे लाइव रीडर और प्रकाशन
दोनों इस्तेमाल करते हैं। पुराने क्रेडेंशियल वैकल्पिक स्रोत बने रहते हैं। संदेश
अनुमति न मिलने पर यह सीमा स्पष्ट दिखती है। अमान्य टोकन, समुदाय टोकन और अलग
खाते का टोकन अस्वीकार होते हैं। संग्रह त्रुटि के बाद दोबारा कोशिश करने से पहले
स्थिति जाँचें।

आयात शुरू होते ही पासवर्ड फ़ील्ड साफ़ हो जाता है। रसीद में कार्य पहचान,
जाँचा गया खाता और क्षमताएँ होती हैं, टोकन या डाला गया URL नहीं। रद्द करने पर
चल रहा अपना काम समाप्त होने का इंतज़ार होता है। पहले ही स्वीकार हुआ संग्रह
सफल ही दिखता है। पृष्ठ फिर खोलना केवल स्थिति पढ़ता है, अनुमति या आयात नहीं
दोहराता और सहमति फिर नहीं भरता। सर्वर फिर शुरू होने पर अस्थायी कार्य स्थिति
साफ़ होती है, सुरक्षित क्रेडेंशियल बना रहता है।

```sh
node js/bin/meta-sovereign.js vk-token status
node js/bin/meta-sovereign.js vk-token start --confirm
node js/bin/meta-sovereign.js vk-token import --confirm
node js/bin/meta-sovereign.js vk-token cancel --id=<operation-id>
```

आयात टर्मिनल में छिपा हुआ इनपुट माँगता है; टोकन कमांड तर्क में न दें।
start/import के बाद status से अंतिम परिणाम पढ़ें। बिना डेस्कटॉप वाले सर्वर में
अनुमति विंडो उपलब्ध नहीं है, आयात उपलब्ध है। `--url` HTTPS या लूपबैक HTTP
मूल पता स्वीकारता है। साझा `GET /api/vk/token` और
`POST /api/vk/token/{start,import,cancel}` पाठ और बाइनरी Links Notation लेते हैं:
start/import में `confirm: true`, import में `value`, cancel में वर्तमान `id`
ज़रूरी है। असफल या अनिश्चित अनुरोध अपने आप नहीं दोहराया जाता।
[सीमित पुनरुत्पादक जाँचें](case-studies/issue-56/vk-token.md)।
