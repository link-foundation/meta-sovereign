# फ़ीचर समर्थन मैट्रिक्स (languages: [en](FEATURES.md) • [zh](FEATURES.zh.md) • hi • [ru](FEATURES.ru.md))

## अभी का दायरा

अभी प्राथमिकता निजी चैट, समूहों और चैनलों के हर संदेश का पूरा प्रदर्शन है। विशेष फ़ीचर रोके हुए हैं और बाद में लौटने के लिए यहाँ सूचीबद्ध हैं। केवल वही लागू किया जाता है जो API (MTProto, लेयर 232, `telegram` पैकेज) या ब्राउज़र में नेटवर्क के वेब ऐप से पहुँच में है; जो केवल आधिकारिक ऐप कर सकते हैं उसे «पहुँच से बाहर» चिह्नित किया गया है।

अभी कुछ नहीं चल रहा। रोका हुआ: R-Y213 से R-Y219।

## संकेत

- **स्थिति**: समर्थित = काम करता है; आंशिक = टिप्पणी में बताई सीमा के साथ काम करता है (अभी चल रहा काम वैसा ही चिह्नित है); रोका हुआ = शुरू होकर उपयोगकर्ता के अनुरोध पर रुका, अधूरा काम worktree में रखा है; असमर्थित = बना नहीं।
- **पहुँच**: API = MTProto विधियाँ (जहाँ पता हैं, नाम सहित); वेब = ब्राउज़र में नेटवर्क का वेब ऐप, विकल्प के रूप में (R-Y38); API + वेब = पहले API, और जब API में ऐसी कॉल न हो या मना करे तो वेब ऐप; पहुँच से बाहर = ऐसी क्षमता चाहिए जो केवल आधिकारिक ऐप में है।
- **आवश्यकताएँ**: [`REQUIREMENTS.hi.md`](./REQUIREMENTS.hi.md) की R-Y पंक्तियाँ जो इसे पूरा करती हैं, जिनमें हुआ काम और ज्ञात सीमाएँ हैं।
- **जाँच**: अधिकांश फ़ीचर नकली (fake) के साथ परखे गए हैं और असली Telegram से जाँचे नहीं गए, जब तक टिप्पणी न कहे। असली स्टोर की प्रदर्शन-गणना (केवल गिनती) में मीडिया photo, document, webpage, poll, contact, dice, story, geo और 283 unsupported संदेश, सभी आम एंटिटी, और ChatJoinedByRequest, InviteToGroupCall, ChatEditPhoto, BoostApply, NewCreatorPending जैसी सेवा क्रियाएँ थीं।
