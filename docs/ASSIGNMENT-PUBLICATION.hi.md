# परीक्षण कार्य के रिपॉज़िटरी (languages: [en](ASSIGNMENT-PUBLICATION.md) • [zh](ASSIGNMENT-PUBLICATION.zh.md) • hi • [ru](ASSIGNMENT-PUBLICATION.ru.md))

[PR 57](https://github.com/link-foundation/meta-sovereign/pull/57) कार्य के लिए रुके फ़ॉर्म में समीक्षा के बाद GitHub प्रकाशन जोड़ता है। **अधिक → फ़ॉर्म** में फ़ॉर्म खोलें, प्रोफ़ाइल चुनें और उत्तरों की योजना बनाएँ। परीक्षण कार्य पहचानने पर सामान्य उत्तर और PDF अपलोड रिपॉज़िटरी की पुष्टि तक रुकते हैं। मौजूदा रिपॉज़िटरी लिंक जाँचने और सहेजने का विकल्प उपलब्ध रहता है।

पहले प्रश्न/फ़ॉर्म सेटिंग में स्थानीय ड्राफ़्ट मॉडल सक्षम करें। प्रकाशन सर्वर के प्रमाणित `gh` और Git क्रेडेंशियल उपयोग करता है; क्रेडेंशियल सर्वर पर रहते हैं। `owner/repository`, सार्वजनिक/निजी दृश्यता, वैकल्पिक HH रिक्ति URL और नियोक्ता के अतिरिक्त नाम भरें। ड्राफ़्ट बनाना संदर्भ पढ़कर निजी पूर्वावलोकन सहेजता है; रिपॉज़िटरी या issue नहीं बनाता। सटीक अंग्रेज़ी issue, आवश्यकताएँ, भाषा, स्टैक, टेम्पलेट स्रोत और दृश्यता जाँचकर स्पष्ट रूप से प्रकाशित करें। सर्वर में क्षमता न होने पर प्रकाशन नियंत्रण अनुपलब्ध हैं।

रिक्ति URL सहेजी गई `assignments` ब्राउज़र नीति से अलग, स्वामित्व वाले ब्राउज़र में खुलता है; डिफ़ॉल्ट में विंडो दिखाई देती है। ज़रूरत पर स्वयं लॉग इन करें। रीडर दिखाई देने वाला शीर्षक, नियोक्ता, कौशल और विवरण पढ़कर ब्राउज़र बंद करता है और केवल सफल परिणाम कैश करता है। रीफ़्रेश स्पष्ट कार्रवाई है। सहेजे HH संदेशों का सटीक फ़ॉर्म लिंक मूल और रीडायरेक्ट URL सहित रिक्ति जोड़ सकता है। विरोधी संबंधों पर स्पष्ट URL दें। संबंध न मिलने पर पूर्वावलोकन संदर्भ की अनुपलब्धता बताता है और मॉडल उपयुक्त समर्थित स्टैक चुनता है।

अलग HTML या सादा पाठ कार्य के लिए निर्देश दस्तावेज़ URL भरें। निर्देश उसी दृश्यता नीति से दूसरे स्वामित्व वाले ब्राउज़र में पढ़े जाते हैं। ड्राफ़्ट के पास अंतिम पृष्ठ का शीर्षक और संग्रह समय जाँचें। निजी ड्राफ़्ट पाठ और फ़िंगरप्रिंट रखता है; पुनर्स्थापना और प्रकाशन उसी स्नैपशॉट का उपयोग करते हैं, दोबारा पृष्ठ नहीं पढ़ते। छिपा पाठ, संपादन योग्य उत्तर और फ़ॉर्म मान बाहर रहते हैं। लॉगिन, सत्यापन, HTTP त्रुटियाँ, PDF/canvas/एम्बेड किए दस्तावेज़ और सीमित पठन सीमा से बड़ा पाठ मॉडल चलने से पहले अस्वीकार होते हैं। ऐसे दस्तावेज़ का पठनीय पाठ संस्करण दें। आगे के दस्तावेज़ लिंक अपने आप नहीं खोले जाते।

पहले Hive Mind की वर्तमान मुख्य **Recommended CI/CD Templates** तालिका पढ़ी जाती है, फिर अंतर्निहित वैकल्पिक सूची; पूर्वावलोकन वैकल्पिक स्रोत बताता है। पद में स्पष्ट भाषा का महत्व संयोग से लिखी तकनीकों से अधिक है। GitHub टेम्पलेट `gh repo create --template` उपयोग करते हैं; अन्य टेम्पलेट इतिहास सहित क्लोन और पुश होते हैं। मालिक की फ़ाइलें सुरक्षित रहती हैं, अनुपस्थित workflow और टेम्पलेट इतिहास जुड़ते हैं। मौजूदा पाइपलाइन बनी रहती है। नए पूर्वावलोकन के बाद फिर प्रकाशन उसी विशिष्ट चिह्नित issue को अपडेट करता है और गायब पाइपलाइन ठीक करता है।

स्थानीय सावधान जाँच अंग्रेज़ी पाठ, ज्ञात नियोक्ता नाम/रूप/लिप्यंतरण तथा फ़ॉर्म और जुड़े निर्देशों (दस्तावेज़ शीर्षक सहित) के लगातार छह शब्दों की नकल जाँचती है। शुद्धता और ऐसे नामों की समीक्षा करें जो ऐप नहीं पहचान सकता। लिखित कार्य के issue में **Deliverable and stack** और अंतिम **Stack** भाग रहते हैं: `docs/` में मूल भाषा का Markdown, मूल लंबाई सीमा, प्रस्तावित स्टैक और परिणाम के लिंक वाला README। प्रकाशन रिपॉज़िटरी, workflow और issue को दोबारा पढ़कर पुष्टि करता है; कार्य का क्रियान्वयन, CI सफलता या नियोक्ता फ़ॉर्म जमा होना प्रमाणित नहीं करता।

## CLI

`forms-read` से सहेजा निरीक्षण `--file` से, या वास्तविक फ़ॉर्म `--url` से लें। मॉडल के लिए मौजूदा `answers model` कमांड उपयोग करें।

```sh
meta-sovereign test-assignment task-name --file=inspection.json --vacancy=https://hh.ru/vacancy/12345 --visibility=private --employer='Employer alias' --dry-run --store=./store
meta-sovereign test-assignment owner/task-name --file=inspection.json --vacancy=https://hh.ru/vacancy/12345 --visibility=private --store=./store
meta-sovereign test-assignment owner/task-name --file=inspection.json --source=https://example.org/instructions --dry-run --store=./store
meta-sovereign test-assignment --draft-id=assignment-draft:UUID --store=./store
```

केवल नाम देने पर प्रमाणित मालिक चुना जाता है; `--owner` भी दे सकते हैं। डिफ़ॉल्ट दृश्यता निजी है। `--dry-run` पूर्वावलोकन सहेजकर प्रिंट करता है; इसके बिना CLI ड्राफ़्ट प्रकाशित करता है। प्रिंट किए सटीक `draft.id` को `--draft-id` से पुनर्प्राप्त करें; मॉडल फिर नहीं चलता। URL के बदले सीमित Lino `--vacancy-snapshot` में `title`, `description`, `company`, `skills` दे सकते हैं। `--refresh-vacancy=true` URL फिर पढ़ता है। SIGINT/SIGTERM मॉडल, ब्राउज़र और कमांड रोककर उनके समाप्त होने की प्रतीक्षा करते हैं, फिर स्टोर बंद होता है।

## API और पुनर्प्राप्ति

विश्वसनीय POST मार्ग मौजूदा पाठ/बाइनरी Lino नेगोशिएशन उपयोग करते हैं:

| मार्ग                           | इनपुट                                                                                                                                       | परिणाम                                                                 |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- |
| `/api/forms/assignment/draft`   | `inspection`, वर्तमान कार्य `revision`, `target`, `visibility`; वैकल्पिक `vacancyUrl`/`vacancy`, `sourceUrl`, `refreshVacancy`, `employers` | निजी `draft`, वैकल्पिक `sourceEvidence`, `state: draft`                |
| `/api/forms/assignment/restore` | `inspection`, वर्तमान कार्य `revision`                                                                                                      | सहेजा ड्राफ़्ट और प्रकाशन प्रयास की स्थिति; GitHub/मॉडल कॉल नहीं       |
| `/api/forms/assignment/publish` | `draftId`                                                                                                                                   | सत्यापित रिपॉज़िटरी, issue, नया कार्य संशोधन या बरकरार `uncertain` चरण |

बाहरी लिखाई से पहले निजी इरादा डिस्क पर सहेजा जाता है। उत्तर खोने पर परिणाम अनिश्चित और फ़ॉर्म रुका रहता है। उसी प्रकाशन की पुनर्प्राप्ति वास्तविक पहचान और चिह्नित issue जाँचती है, अज्ञात परिणाम वाले निर्माण दोहराती नहीं। फ़ॉर्म दोबारा खोलकर पढ़ें/योजना बनाएँ, सहेजा ड्राफ़्ट पुनर्स्थापित करें और उसी का प्रकाशन पुनर्प्राप्त करें। बदला कार्य/मॉडल, दूसरा लंबित ड्राफ़्ट, पुनर्निर्मित रिपॉज़िटरी या मालिक द्वारा संपादित issue पुराने प्रकाशन को रोकते हैं। सकारात्मक पुष्टि के बिना परिणाम को मानवीय निरीक्षण चाहिए।

निजी संस्करण 1 नेमस्पेस: `assignment-draft:` (समीक्षित पाठ/संदर्भ), `assignment-publication:` (भेजे प्रभाव/रसीदें), `assignment-vacancy:` (सफल स्नैपशॉट), `form-vacancy:` (सटीक URL और HH संदेश स्रोत)। मौजूदा रिकॉर्ड आकार संगत रहते हैं। निजी कार्य और रिक्ति पाठ पर सामान्य बैकअप/स्टोरेज नीति लागू है। वैकल्पिक पहचान/स्थिति ट्रेसिंग डिफ़ॉल्ट में बंद प्रश्न निदान उपयोग करती है।
