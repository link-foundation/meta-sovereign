Fixes #43

The original package check hid installation/startup failures behind one timeout; a heavy backup case competed with the ordinary matrix, and Linux WebKit failures were explicitly allowed to pass. This PR separates the package phases with durable diagnostics, runs the bounded backup regression independently, and requires the complete 41-suite browser manifest, including the latest main message-history feature in Chromium and native macOS WebKit.

The wider audit compares 356 CI/configuration/test-reference files across all three revision-pinned template trees and maps all 17 linked best-practice principles. It fixes whole-change detection and recursive coverage; rejects missing link reports and unknown registry/API/Git states; replaces mutable remote release loaders with locked local dependencies; protects validated source through versioning/publication; adds workflow/security/dependency gates and early publisher feasibility checks; and retains the existing release, desktop, Pages, documentation and runtime features.

KaTeX and the maintained Telegram client remove the vulnerable/deprecated runtime paths. An exact electron-builder 27 prerelease removes deprecated builder chains; its configuration, provenance API and native FPM setup are migrated while preserving the existing updater-6 channel. This prerelease build-tool choice requires every native packaging target to pass. Unsigned update manifests/Windows artifacts remain explicit existing channel behavior.

Reproductions and regression coverage include temporary Git histories, missing-report and fake-API fixtures, child-exit/health deadlines, real nonzero shell exits, release-tree drift, dependency-lock deprecations and React sticker-key warnings. Focused local checks use concurrency 1; full runtime/browser/stress/native-build validation runs in GitHub CI. No real Telegram accounts or the user's app data are used.

The independently staged updater still uses a deprecated comparator upstream. A scoped exact npm alias to `lodash.isequalwith@4.4.0` preserves both two-argument boolean comparisons; clean-install/audit and real updater-cache checks pass without warning suppression. Every target validates equal/changed metadata and missing files after installation. The [upstream report](https://github.com/electron-userland/electron-builder/issues/10016#issuecomment-6472315403) includes reproductions and a suggested permanent migration.

A bounded three-worker probe isolated Windows Deno's abrupt AES exit to native cifrante construction (0xC0000005); the same portable round trips pass. The centralized Telegram entry path now selects the existing WASM backend specifically on Windows Deno. Other selections remain intact, full crypto comparisons stay enabled, and the raw native reproducer and default-off diagnostics are retained. The [upstream report](https://github.com/sanyok12345/cifrante/issues/1) contains exact environment, output, workaround and suggested code changes.

Successful Windows packaging logs also exposed Node DEP0190 from raw shell argument arrays. All desktop, registry, mobile and package-smoke npm/npx paths now share exact-pinned `cross-spawn`, preserving literal arguments and failure status. A finite before/after probe and npm/npx tests with fatal deprecations verify the replacement.

The archive exposed a pre-commit discovery bug: lint-staged could select a downloaded snapshot’s own configuration before root exclusions applied. The hook now explicitly uses root `package.json`; a real-Git regression proves nested tasks never run while maintained files remain checked. Initial task execution, rollback and unchanged reference hashes are retained in the investigation.

Windows Deno also exposed slow shared GitHub and server-fetch fixture teardown. Bounded TCP/incomplete-request tests fail before the fix; every owned HTTP/TCP/TLS fixture now shares explicit connection cleanup, with default-off count/duration tracing and no deadline increase. Focused coverage passes 50 Node tests, 34 Deno tests/50 steps and 20 additional mail-security cases. Repeated GitHub ARM allocation failures left Node/macOS and WebKit unexecuted; those jobs now use the supported pinned native Intel pool. All nine runtime/OS targets and both full browser gates remain required, with Bun/Deno/desktop retaining ARM coverage.

Successful Checks logs also exposed a Rustdoc bare URL and temporary-Git LF/CRLF warnings. The link is repaired, all three documentation build paths reject warnings, and the hook fixture owns its line-ending policy. Before/after probes verify both faults without changing user Git settings.
